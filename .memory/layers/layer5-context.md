- 报表 SQL 禁令：禁止嵌套相关子查询，必须 WITH CTE + LEFT JOIN。
- 打包：Windows 给 Linux 的压缩包用 	ar -a -cf（正斜杠路径），勿用 Compress-Archive（反斜杠毁目录）。
