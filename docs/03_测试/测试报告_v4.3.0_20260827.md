## 5. 关键 Bug 修复清单

### 5.1 上午批次（v4.3.0 API 层验证）

API 层 51 项全部返回 200/code=0，未发现后端接口级 Bug。

测试过程中发现并修复的**测试脚本问题**（非系统缺陷）：
- 登录返回字段名为 `accessToken`（非 `token`），脚本已修正
- product-prices 返回结构用 `list` 字段（非 `records`），脚本已修正
- product-prices 第一条记录 status=inactive，需过滤 active 状态产品
- Admin audit-logs 正确路径为 `/api/admin/logs/platform-audits`
- Dashboard 正确路径为 `/api/dashboard/summary`（非 `/api/dashboard`）
- Approval instances 正确路径为 `/api/approval/admin/instances`

### 5.2 下午批次（v4.3.1 用户浏览器走查发现，共 4 个 BUG，全部修复并重测通过）

> 背景：上午 API 层全过但仅覆盖 L2 层；用户下午在真实浏览器走查业务流程时发现 4 个 API 层测试无法暴露的 BUG（交互层 L4 / 回显层 L3 缺陷）。修复版本 v4.3.1（镜像 v433，Flyway 追加 V134）。

| BUG# | 严重级 | 模块 | 现象（用户实测） | 根因 | 修复 | 重测结果 |
|---|---|---|---|---|---|---|
| BUG-A | **Critical** | 代金券/审批 | 订单 SO-20260827-00001 使用代金券 VC1OI0Q48C 提交后审批**拒绝**，代金券未返还，状态仍为 USED | `SalesOrderApprovalCallback` / `SalesReturnApprovalCallback` 审批拒绝分支只回滚业务单，未调用券释放；券在提交时已置 USED | 审批拒绝时调用 `voucherService.release()` 将券 USED→ISSUED 并清空占用关联；`@Lazy` 注入 + `backend/lombok.config`（`lombok.copyableAnnotations += org.springframework.context.annotation.Lazy`）解决 VoucherService 与审批回调的循环依赖 | 浏览器走查：拒绝后券状态恢复 ISSUED、可再次选用 ✅ |
| BUG-B | 高 | 销退单新建页 | ①无法主动选择经销商（变成"选出库单后自动带出"的禁用文本）；②出库单弹窗里经销商名称是**自由文本输入**而非选择器；③原有按批号、序列号筛选条件丢失 | 重写销退页时凭记忆重建，未先盘点旧功能，把"重写"做成了功能减法（违反功能对照原则） | 页面返工：字段顺序改为 **经销商 → 发货仓库 → 发货单 → 退货原因**；经销商改 el-select 远程搜索；未选经销商/仓库时"选择发货单"按钮 `disabled` + tooltip 门禁；出库单弹窗恢复批号 batchNo / 序列号 serialNo / 仓库 warehouseId 三个筛选条件；后端 `SalesReturnController` 增 warehouseId 参数、`SalesReturnService` 加仓库过滤 + 同仓库校验；弹窗中已选经销商以 el-tag 只读展示，禁止重复录入 | 浏览器走查：四级选择顺序、筛选缩小结果集、跨仓库单选拦截均生效 ✅ |
| BUG-C | 中 | 销退单 | 销退行未保存/回显序列号 | `RmaOrderLine` 实体缺 serialNo 字段 | 实体加 serialNo + V134 迁移 `rma_order_lines` 加列；`RmaOrderService.enrichOrders` 补仓库/序列号回显 | 销退单详情序列号正常回显 ✅ |
| BUG-D | 高 | 销售订单 | 订单 SO-20260827-00003 保存后**重新打开**，经销商字段为空且价格报错（价格查不到） | 重开/编辑回显时行载荷字段名不一致（详情返回 `id`/`productId` 混用），makeLine 未做兼容导致 productId 为 null，计价引擎查价失败 | `OrderCreate.vue` makeLine 改为 `p.productId ?? p.id ?? null` 兼容多种载荷；`MOrderCreate.vue`（H5）与 `ResourcePicker.vue` 同步修复 | 浏览器走查：重开 SO-00003 经销商/产品/价格全部正常回显 ✅ |
