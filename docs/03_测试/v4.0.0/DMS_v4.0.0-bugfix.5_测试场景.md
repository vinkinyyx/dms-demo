## 二、手工验证要点

1. 抽屉几何：在 1600×900 视口下，抽屉与 `.el-main` 完全重合；折叠侧边栏后 `--dms-sidebar-w` 切换为 64px，抽屉随之变宽。
2. 销售订单折扣：前端 `headerDiscount` 对 PERCENT 按百分比计算，后端 `V4Money.discount` 同样把 >1 的值除以 100，前后端一致。
3. 销退审批回调：`SalesReturnApprovalCallback` 在 onApproved/onRejected/onReturned/onWithdrawn 写入 operation_log(businessType=salesReturn)。
4. 数据迁移：V104 执行后，SO-20260819-00015 amountInclTax=4000，discountAmount=400，finalAmount=3600。

## 三、已知不纳入本次范围

- 产品组合 BOM 子件按经销商价格维护、汇率维护联动报表等为后续迭代项，本次仅确保列表/只读/新建/编辑页面可正常打开且不报错。
