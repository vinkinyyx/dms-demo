## 一、本次修复范围

围绕反馈的 6 大模块逐项修复：

1. **产品管理**：状态/分类筛选可用；编码/查看进入只读页；废弃单价税率；移除批量删除；只读页展示操作日志；布局紧凑化。
2. **产品组合（BOM）**：编码/查看进入只读页；移除删除；“新建版本”按钮将原版本置历史并生成自增版本，新版本仅可改子件、母件头锁定；版本号系统生成；只读页展示日志。
3. **产品价格**：创建后不可编辑/删除，仅可生效/失效或到期自动失效；新增只读查看；按经销商维护子件价格，BOM 母件不可建价；含税价+税率可编辑自动算不含税（4 位小数）；币种使用 CNY/USD/EUR 字母码。
4. **促销规则**：编码/查看进入只读页；移除删除，仅启用/停用或到期停用；按促销模式动态控制明细必填；移除折扣方式/折扣值（折扣只在订单层）；只读页展示日志。
5. **销售订单**：编码/查看进入只读页；状态/经销商筛选可用、日期筛选生效；筛选与按钮布局整齐；选母件带出树形子件；母件不打折、子件数量按配比只读；行折扣按整行；展示命中促销；补齐提交按钮；保存/提交不再做授权校验；修复重复保存提示与取消/返回 404；模拟出库；整单金额折扣按比例分摊到每 EA（4 位小数）并传递出库单。
6. **销退订单**：布局紧凑、备注多行；选择发货单排除无可退数量；数量整数校验并修复历史小数数据；退货带出原订单价格；提交审批不再 404；只读页展示操作日志。

## 二、关键技术修复

- 通用列表 `CrudView` 修复：
  - 行操作 `computed` 未正确返回数组，导致操作列空白；
  - 自定义行按钮（新建版本/生效/失效/启用/停用）被误隐藏；
  - `versionStatus` 过滤误伤无版本字段的模块。
- 操作日志统一：合并 `audit_logs`（resourceType/resourceId）与 `operation_log`（businessType/businessId）两个数据源，产品/BOM/价格/促销/订单/销退只读页均可展示时间轴。
- 订单列表筛选：后端新增 `dateFrom/dateTo/dealer` 参数别名，前端筛选下拉回退列内选项并远程加载经销商。
- BOM 计价/折扣：修复 BOM 仅展开一个子件、编辑新版本唯一约束 500、行折扣按 EA/子件倍增等问题。
