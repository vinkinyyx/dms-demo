# DMS v4.0.0-bugfix.8 发布说明

## 修复内容
- 修复 EVERY_N 赠品促销不生效的问题。
- 赠品直接展示为订单明细锁定行，随订单试算动态更新。
- 满减/整单折扣按非赠品、非 BOM 母件行分摊。
- 销售订单新增后端试算接口，前端金额以后端为准。
- BOM 母件不参与销售出库和完成状态判定，BOM 订单可一次性全部出库。
- 销退明细展示平摊单价、行总价和汇总退货金额，金额由后端按原出库行重算。
- 加宽销售订单经销商字段，压缩销退原发货单区域。
- 新增订单域深度 E2E 自清机制，测试后自动清理本次生成的订单、销退、出库和审批数据。

## 验证要点
- PRD-J002 数量 6 命中“买2送5”生成 PRD-J003 赠品 15。
- BOM 订单生成出库后状态为 COMPLETED。
- 销退单保存/查看/提交金额一致。
- 订单详情页 `/orders/:id` 可见赠品行标签，测试结束后列表无新增临时单号。
