# DMS v4.0.0-bugfix.5 发布说明

发布时间：2026-08-19
测试环境：http://43.128.145.141

## 一、全局问题

1. 所有基础数据/业务菜单的新建、编辑抽屉统一为「只占据列表+筛选区域」（顶部留 topbar，左侧跟随侧边栏宽度，侧边栏折叠时自适应变宽），底部"取消/保存"按钮始终可见，不再被遮挡。
2. 销售出库列表移除多余的「确认/取消/删除/编辑/提交/审批」行按钮，仅保留「查看」，点击不再跳 404。
3. 促销规则新建不再卡死：重写了促销模式/明细列的联动 watcher，切换"满A赠B / 满A减钱"时只刷新字段可见性，并可正常添加明细行。

## 二、销售订单

1. 整单折扣按类型计算：百分比按 `标准金额 × 百分比`（如 10% = 400，最终 3600），固定金额按金额扣减。
2. 整单折扣选择器、金额/百分比输入框与其他字段对齐；备注独立占一整行（多行文本）。
3. 历史数据修正：SO-20260819-00015 的 10% 整单折扣由错误的 3990 修正为 3600（数据库迁移 V104）。
4. 列表页不再显示行内"提交"按钮（提交仅在编辑页内），草稿单保留"编辑"按钮。

## 三、销退订单

1. 只读页字段修正：退货原因、退货金额、状态、批次/序列号、操作日志正确展示。
2. 只读页不再显示"原发货单选择/重新选择"区域。
3. 操作日志补充审批动作：审批通过、驳回、退回、撤回均写入操作日志。
4. 已审批销退单可通过「生成红字销售出库」按钮生成红字出库单（GIR 单号）。
5. 暂存/提交请求加 `skipDuplicate`，不再误报"请求正在处理中，请勿重复提交"。
6. 已退/可退数量在选择发货单时实时计算（含审批中、已审批、收货中、已完成的销退锁定量）。
7. 新建/查看/编辑页均可正常打开，不再白屏。
