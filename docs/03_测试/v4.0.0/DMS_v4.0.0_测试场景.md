# DMS v4.0.0 测试场景

## 1. 租户能力开关
1. 平台后台创建启用库存租户，采购、库存、仓库、供应商菜单可见且 API 可用。
2. 创建关闭库存租户，采购、采退、库存、仓库、供应商菜单不可见，直接调用 API 返回业务错误。
3. 关闭库存租户仍可创建销售订单、销退订单并查看只读销售出库结果。
4. 启用库存租户存在未完成采购或库存单据时，尝试关闭库存模块应失败并提示原因。
5. 历史采购/库存数据不会因关闭模块被删除，重新启用后可恢复查看。

## 2. 价格主数据
1. 维护 SKU 全局采购价，采购订单不显示价格和税率输入，保存时取价格主数据。
2. 维护经销商销售价和全局销售价，经销商下单优先取经销商价。
3. 经销商无专属价时自动取全局价；两者都不存在时提交失败。
4. 同一产品、经销商维护两段不重叠生效价格，提交时按提交日期取价。
5. 同一产品、经销商维护重叠时间段价格，保存应失败。
6. 草稿期间价格变动不改变已保存展示，提交时刷新为最新有效价。

## 3. 销售订单金额
1. 普通 SKU 订单只允许输入数量、行折扣和整单折扣，不允许输入单价和税率。
2. 行固定金额折扣后金额正确，按行税率拆分不含税金额和税额。
3. 行比例折扣后金额正确，前端仅展示含税金额。
4. 整单固定金额折扣按行金额占比分摊，尾差不导致合计不一致。
5. 整单比例折扣按行金额占比分摊，最终金额不得小于 0。
6. 折扣导致某行金额小于 0 时，提交失败并提示具体产品或行号。
7. 草稿可保存、编辑、删除；提交后不可删除；审批驳回后可重新编辑提交。
8. 已审批但无出库结果可取消；已有部分出库时整单取消失败。

## 4. BOM
1. 产品组合升级为 BOM，支持版本号、固定子件、子件数量和生效状态。
2. 采购订单不能选择 BOM 母件，只能选择 SKU。
3. 销售订单选择 BOM 后展开子件，子件继承 BOM 版本和分组号。
4. BOM 有销售价时，按子件标准含税金额占比分摊成交价。
5. BOM 无销售价时，成交价等于子件销售价合计。
6. BOM 母件不能直接打折，子件行可打折且金额不能小于 0。
7. 子件可以分批发货，不同仓库拆成不同销售出库子单。
8. 未发货子件可以关闭；关闭后不影响已发货部分和退货。
9. 订单提交后保存 BOM 版本，后续 BOM 主数据变更不影响已提交订单。

## 5. 促销
1. 满 A 赠 B，A 为具体 SKU，满足门槛后赠送 SKU，赠品行金额为 0。
2. 满 A 赠 B，A 为产品层次节点，节点下所有 SKU 和 BOM 子件数量合并统计。
3. 赠品为 BOM 母件时规则保存失败。
4. 满 A 赠 B 支持仅赠一次和每满 N 个循环赠送。
5. 满 A 减钱比例折扣只作用于命中 A 的行。
6. 满 A 减钱固定金额按命中 A 行金额占比分摊。
7. 促销折扣、行折扣、整单折扣叠加后金额正确且不小于 0。
8. 赠品可以出库并可以以 0 元退货。

## 6. ERP 出库与模拟发货
1. 关闭库存租户审批销售订单后不生成本地库存出库单，只记录 ERP 推送状态。
2. ERP 正向回调创建销售出库子单，一个子单只有一个仓库。
3. ERP 正向回调支持部分发货，订单状态变为部分出库。
4. 同一 idempotencyKey 重复回调不重复生成出库行。
5. 模拟发货按钮受权限控制，生成的出库结果与 ERP 回调一致，不扣减库存。
6. 销退审批通过后记录红字出库推送状态，红字回调后更新销退状态和可退数量。

## 7. 销退订单
1. 销退必须选择销售出库子单，不能直接选择销售订单头。
2. 可按经销商、日期范围、订单号、出库单号、产品、批号/序列号、医院/终端搜索出库子单。
3. 可退数量等于已出库数量减已锁定数量减已红字出库数量。
4. 销退提交即锁定可退数量，另一张销退单不能重复选择已锁定数量。
5. 销退驳回或取消后释放锁定数量。
6. 红字部分出库后销退状态为部分红字出库，全部出库后完成。
7. 销退价格继承原订单子件最终含税单价，不显示折扣输入。

## 8. 手术报台
1. 所有租户均可手填批号或序列号，不校验库存是否存在。
2. 序列号管理产品未填序列号时提交失败。
3. 批次管理产品未填批号时提交失败。
4. 支持扫码、粘贴和导入批号/序列号，提交后不扣减库存。

## 9. 回归范围
- 后端 Maven 编译通过。
- 前端业务端和平台后台 Vite 构建通过。
- 数据库 Flyway 迁移可重复执行。
- 销售订单、销退订单、价格主数据、BOM、销售出库结果、手术报台核心 API 回归通过。
- 测试环境部署后使用管理员和经销商账号进行端到端冒烟测试。
