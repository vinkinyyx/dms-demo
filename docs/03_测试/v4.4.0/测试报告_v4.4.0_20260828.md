## 7. 联调中发现并修复的缺陷
1. 开票预览 500：产品名 SQL 引用 products 不存在的 name 列 → 改 name_cn（同时修复错误信息只显示 ID 的问题，现显示 编码+名称）。
2. 开票落库 500：order_lines INSERT 增加 batch_no/serial_no 后参数错位，line_zero 落 null 违反 NOT NULL → 重排绑定顺序。
3. 开票提交 400 Unknown alias warehouse_id：回调/提交从 order_lines 读不存在的 warehouse_id → 移除，仓库以台账为准。
4. dealer_credit_profiles 不落数：recompute 的 INSERT 未绑参 + ON CONFLICT 无法推断部分唯一索引 → 补绑参并指定冲突目标。
5. 前端 Console：开票禁用 ResourcePicker 缺 resource 致 lookups/undefined 404；寄售表 row-key 位置错误告警 → 均修复。
