## 场景清单

### 1. 进销存全闭环 + 批次/序列号/UDI 追溯
- 采购订单 → 审批 → 收货入库（父单/子单多次 partial 收货，入待检 Q 态）→ 三态库存（合格 U / 待检 Q / 不合格 B，含隔离态）→ 销售订单审批通过自动生成 GI 出库单 → 按批次/序列号逐件发货扣减 → 销退（RGR 入待检）/ 采退（RGI 出库）；库存调整、跨仓移动、盘点；`inventory_transactions` 按月分区、不可篡改。
- **价值**：系统骨架，所有商务、报表、协同都挂在单据流上；医疗器械「批号/序列号/UDI 全程可追溯」是强监管红线。

### 2. 多租户 SaaS 平台 + 厂家↔经销商跨租户订单协同（v4.5.0 特色）
- 厂家/经销商两类租户，平台后台独立开通与一对一绑定；经销商向「平台厂家」下采购单 → 厂家租户自动生成销售单（产品对码自动转码）；厂家出库 → 经销商租户自动生成已审批采购单 + 待收货入库单；台账 `cross_tenant_doc_links` 行级溯源、幂等防重；物料缺对码明确阻断并提示编码。
- **价值**：一套 SaaS 跑通供应链上下游，数据隔离但单据自动流转，是普通单租户 ERP 不具备的网络效应。

### 3. V4 计价引擎：合同价 → 全局折扣 → 促销 → 标准价
- 定价优先级链：合同价格协议 > 产品/客户全局折扣 > 促销（满减/数量折扣/赠品）> 标准价；支持 NORMAL/FIXED_PRICE/ZERO_ORDER/VOUCHER 模式；`/api/v4/calc/preview` 实时试算；代金券模板/发放/核销全链路，提交占用 USED、审批通过核销、**驳回/退回/撤回自动释放回 ISSUED**；BOM 母件 0 金额、子件承载价值、组件价回退单品价。
- **价值**：商务政策最复杂的部分，且与审批回滚强耦合，历史 Bug 最集中。

### 4. 寄售（代销）业务闭环（v4.4.0 行业特色）
- 补货订单（0 金额铺货，禁折扣/促销/券）→ 发货后按「经销商 + SKU + 批号 + 序列号」记寄售台账与流水（REPLENISH_IN / INVOICE_LOCK / INVOICE_DEDUCT / INVOICE_RELEASE）→ 开票订单必须从寄售库存弹窗整行拣选（提交预占、审批实扣、驳回释放）→ 红字补货单红冲（SOR，序列号豁免唯一约束）→ 寄售金额按标准价实时汇总；配套经销商信用额度/账期/寄售额度，超额超期触发审批而非硬拦截。
- **价值**：「先铺货后按实际使用开票」是高值耗材经销主流模式，台账维度细到序列号。

### 5. 统一审批工作流 + 关联资源回滚
- 销售/采购/销退/采退/合同全部接入工作流；审批通过触发下游自动建单（GI 出库等）；**拒绝/退回/撤回必须回滚代金券、库存锁定、可退量、寄售预占**；审批卡片结构化摘要、PC + 移动端审批闭环（assignee 门禁）、超时催办升级、委托代理、审批监控页。
- **价值**：业务正确性的闸门。v4.3.0 曾因「只测通过不测驳回」漏过代金券不返还等严重 Bug。

### 6. 手术报台：移动端扫码 + 拍照的终端流向追溯
- 销售在手术室手机填报：医院/医生/患者/仓库/手术日期 + 产品使用明细；扫码自动带出产品/批号/序列号、现场拍照上传；按授权范围过滤经销商与医院；销售岗只看自己负责的经销商数据；报台统计报表可穿透到报台详情。
- **价值**：产品流向终端医院的最后一环，是行业合规（UDI / 不良事件追溯）的关键证据。

### 7. 移动销售工作台（H5 四 Tab + 智能下单向导）
- 只服务销售人员：首页（个人 KPI + 快捷入口）/ 订单（移动下单，行内编辑数量单价税率、底部合计）/ 报台 / 我的；v4.4.4 新增「智能下单」对话式向导；移动审批待办；令牌静默续期（8h access / 7d refresh）。
- **价值**：销售真实高频场景就在手机上，与现场成单率直接相关。

### 8. 经销商 360 画像 + 报表中心 + 可拖拽仪表盘
- 13 张报表（销售业绩排行/产品 TOP10/销售明细/库存周转/呆滞超期/订单追溯/拒单率/应收账龄/返利折扣对账/合同台账/授权余额/借货余额/手术报台统计）统一筛选条 + 导出 xlsx + 行内穿透；画像页目标 vs 实际达成率、月度趋势、返利/订单/合同/报台页签；仪表盘 8 项 KPI + 6 块图表、vuedraggable 自定义布局。
- **价值**：厂家管理经销商网络的经营分析抓手。

### 9. 合同模板驱动 + 授权前置管控
- 合同工作台全生命周期（草稿 → 审批 → 生效 → 终止/到期）、版本快照与审批轮次留痕、Word 模板字段自动回填成稿；合同价格明细是计价最高优先级；授权/临时授权决定经销商「能订什么、有效期到何时」，下单出库前置过滤。
- **价值**：把商务政策落地为系统硬约束，防止超范围经营。

### 10. 平台运营底座：租户开通/自助注册/RBAC/日志审计/模块开关
- 经销商 H5 自助注册 → 平台审核 → 自动建租户 + 管理员 + 角色模板；RBAC（菜单/按钮/数据权限，销售岗按负责经销商过滤）；操作/登录/接口日志中心（报文存 MinIO、敏感字段脱敏、按保留期清理）；租户进销存模块开关（厂家默认关、经销商不受限，前后端双重门禁）；全局字典、消息铃铛待办。
- **价值**：SaaS 可运营、可合规、可规模化交付的地基。

## 排序逻辑

- **1–2** 是「没有就不成为系统」的业务主干与平台差异化能力；
- **3–5** 是交易正确性与最复杂的业务规则（计价、寄售、审批回滚）；
- **6–7** 是医疗器械行业场景与移动端抓手；
- **8–10** 是经营分析、商务管控与 SaaS 运营底座。

最能体现「医疗器械经销 DMS」而非通用进销存的行业特色组合：
**跨租户订单协同（2）+ 寄售代销（4）+ 手术报台追溯（6）**。
