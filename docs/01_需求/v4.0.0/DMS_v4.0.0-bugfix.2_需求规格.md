# DMS v4.0.0-bugfix.2 需求规格

本次迭代针对 v4.0.0-bugfix.1 测试反馈，统一主数据与单据的只读体验、价格与 BOM 维护规则、促销规则交互、销售订单 BOM 展示与折扣分摊、销退整数约束等问题。适用于产品管理、产品组合、产品价格、促销规则、销售订单、销退订单六个模块。

## 1. 通用规则
- 产品管理、产品组合、产品价格、促销规则、销售订单、销退订单的“编码链接”和“查看”按钮均进入独立只读页面，不再复用编辑抽屉/编辑页。
- 只读页展示完整字段、明细与操作日志；编辑页仅用于新增和编辑，布局统一紧凑整齐，输入框宽度一致且内容完整展示，备注使用多行文本。
- 操作日志统一在只读页中以时间线或表格展示字段变更、操作人、时间。
- 所有列表筛选区与工具栏按钮对齐排列，状态、经销商等下拉使用远程选项加载，不再出现空下拉。

## 2. 产品管理
- 产品表的单价(currentPrice)、税率(taxRate)字段彻底废弃，不在列表、表单、只读页出现；价格统一在“产品价格”维护。
- 列表状态下拉使用 active/inactive 选项，产品分类下拉使用产品分类树接口加载。
- 列表移除批量删除按钮。
- 产品编码链接和查看按钮进入产品只读页，只读页展示基本信息、规格、医疗器械属性和操作日志。

## 3. 产品组合（BOM）
- BOM 编码链接和查看按钮进入 BOM 只读页，展示母件头信息、版本信息、子件列表、操作日志。
- BOM 不提供删除按钮；历史版本保留。
- 版本号由系统自动生成，用户不可手填。
- 不在编辑态直接把 BOM 改为历史版本。当前版本提供“新建版本”按钮：点击后将当前版本标记为历史，复制生成新版本（版本号自增），新版本母件头部字段只读，仅允许编辑子件，保存后成为当前版本。
- BOM 母件不维护价格；每个子件作为独立 SKU 在产品价格中按经销商维护销售价，允许某个子件价格为 0。

## 4. 产品价格
- 价格一经创建不可删除、不可编辑，只能标记为生效/失效，或按有效期自动失效。
- 列表提供查看按钮，进入价格只读页。
- 价格按经销商维护；支持全局价(partnerType=GLOBAL)与经销商价(partnerType=DEALER)。
- BOM 母件不维护价格；价格维护对象为子件/普通 SKU（products.is_bundle=false）。
- 含税销售价、税率可编辑，不含税销售价只读自动计算，保留 4 位小数：不含税价 = 含税价 / (1 + 税率)。
- 采购价同理：含税采购价、税率可编辑，不含税采购价只读自动计算。
- 币种使用字母代码(CNY/USD 等)；币种信息在报表及出现币种的字段中带出。本期暂不维护汇率，不做汇率换算。
- 同一 SKU、合作方、时间段的价格不允许重叠。

## 5. 促销规则
- 规则编码链接和查看按钮进入促销只读页，展示规则头、规则明细、操作日志。
- 不提供删除按钮；只允许启用/停用，或按有效期自动停用。
- 规则明细根据促销模式动态显示与校验：
  - 满A赠B：必填 命中对象A（SKU 或产品层次）、门槛数量A、赠品B（SKU，不可为BOM母件）、赠品数量、是否仅赠一次/每满N循环。
  - 满A减钱：必填 命中对象A、门槛数量A、减免金额。
- “满A”一律按 A 的数量判定。
- 促销规则不维护折扣方式、折扣值等通用折扣字段；具体折扣只在订单层（行折扣/整单折扣）体现。

## 6. 销售订单
- 订单号链接和查看按钮进入销售订单只读页，展示表头、明细（含 BOM 母子件树形）、金额、操作日志。
- 编辑页/只读页布局紧凑整齐，字段宽度一致，备注为多行文本。
- 列表状态、经销商下拉使用远程选项；筛选区与工具栏对齐。
- 列表日期范围筛选必须生效（按创建时间）。
- 明细选择 BOM 母件后自动带出子件，采用母件行+子件行的树形展示。
- 母件行可修改数量；子件数量按 BOM 配比自动计算，不可手改。
- 母件行不允许打折，所有折扣作用于子件行；母件行金额为子件合计（只读）。
- 行折扣作用于整行金额（单价×数量），不是每个 EA；金额折扣直接减整行，比例折扣按整行金额比例。
- 命中促销时在明细中展示促销命中标识与促销折扣金额。
- 编辑页提供“提交”按钮。
- 保存和提交时不做商品授权校验，不提示“订单授权校验失败”。
- 修复重复提交问题：保存中按钮置灰，后端基于幂等/状态拦截重复请求，不再弹出“请求正在处理中，请勿重复提交”。
- 点击取消返回列表页，不得跳转 404。
- 已审批订单详情提供“模拟创建出库”按钮，权限仅租户管理员；生成模拟出库结果不扣减库存。
- 整单折扣（尤其固定金额）按各行金额占比分摊到每一行每个 EA（即落到行单价 unit_price），与行折扣、促销折扣一起记录到订单行，并传递到销售出库行；销退按出库行单价退货。
- 补充带价格的销售出库测试数据，用于销退验证。

## 7. 销退订单
- 编辑页/只读页布局紧凑整齐，字段宽度一致，备注为多行文本，字段内容完整展示。
- 选择出库单时排除没有任何可退数量的单据。
- 发货数量与退货数量均为整数；修正现有小数测试数据（如 GI-20260816-00009）。
- 退货时自动带出原订单/出库行的最终含税单价。
- 提交审批成功后跳转回销退列表或详情，不得跳转 404。

## 附录：v4.0.0-bugfix.3 业务菜单统一规范（2026-08-18）

所有业务菜单（基础数据、合同管理、订单业务、库存业务、手术与营销、业务报表、产品对码、审批中心、用户与权限）统一遵循：

1. 列表点击业务编码链接或"查看"按钮进入只读页；仅"编辑"进入编辑页。
2. 工具栏按钮逐页可用；移除所有"批量删除"。
3. 编辑页/只读页采用紧凑三列布局，标签等宽、输入框等宽 100%，长字段占整行并完整展示。
4. 筛选下拉（状态、分类、经销商、仓库等）必须有可选内容。
5. 只读页统一展示"操作日志"（合并审计日志与业务操作日志）。
6. 列表宽度按浏览器分辨率自适应，操作列固定右侧、无大片留白。
7. 行操作按钮超过 2 个时折叠到"更多"下拉。

# 附录：v4.0.0-bugfix.4 补充（2026-08-19）

本附录为对上述需求的实现修正，不改变业务规则：

1. **BOM 子件展开完整**：销售订单选择 BOM 母件时，必须展开该版本下全部子件（按 `sort_order` 排序），不得只取第一个子件。
2. **BOM 取价规则落地**：订单中 BOM 金额恒等于各子件（数量 × 配比 × 该子件经销商价）之和；母件历史 `bundle_price`/OVERRIDE 打包价不再参与订单计价。子件价格可各自为 0。
3. **产品价格不可删除落地**：`DELETE /api/product-prices/{id}` 返回业务错误；`PUT` 仅用于状态变更；生效/失效使用独立 `POST /{id}/activate`、`POST /{id}/deactivate`。
4. **测试环境业务账号**：租户 `default` / `sys_admin` / `Dms@123456`（原 `admin/Sh123456` 已停用）。

## 附录：v4.0.0-bugfix.4 续作补充约定（2026-08-19）

1. BOM 判定以 `product_bundles` 是否存在 `version_status='active'` 记录为准；`products.is_bundle` 列不作为依据。
2. BOM 母件不维护任何价格（接口与 SKU 选择器均拦截），价格只维护到子件/单品，且按经销商维度维护。
3. BOM 行折扣作用于整行，按各子件标准金额比例分摊到子件；母件不落订单行、不打折。
4. 整单（表头）折扣仅分摊一次，按各行折后金额比例分摊，避免重复扣减。
5. BOM 新版本以草稿态创建并可编辑子件；原活动版本保持 active 直至草稿“发布”，发布时原版本转历史。
6. 价格一经创建只能切换生效/失效状态，不可删除，不可修改金额、税率等其它字段。
