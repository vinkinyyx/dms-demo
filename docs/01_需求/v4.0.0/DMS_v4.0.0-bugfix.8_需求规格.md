# DMS v4.0.0-bugfix.8 需求规格

**版本**: v4.0.0-bugfix.8  
**日期**: 2026-08-21  
**测试环境**: http://43.128.145.141

## 1. 促销赠品
1. 销售订单选择目标产品并满足促销规则时，赠品必须直接显示在订单明细中。
2. 赠品行展示产品编码、名称、规格、数量、标准价和最终金额，最终金额为 0。
3. 赠品不允许修改产品、数量、折扣，也不允许删除；数量随购买数量和规则自动刷新。
4. 满减促销金额直接体现在订单最终总价，并按计费行可分摊余额分摊到非赠品、非 BOM 母件行。
5. 示例规则“买2送5 / 每满2送5”购买 PRD-J002 数量 6 时，应生成 PRD-J003 赠品 15 个。

## 2. 销售订单
1. 新增/编辑页经销商字段加宽，长经销商名称不得被明显截断。
2. 订单试算以服务端结果为准，BOM 展开、赠品、折扣和金额均由后端计算返回。
3. BOM 母件仅作为结构展示，不参与收费和出库。
4. 对已审批 BOM 订单点击“生成销售出库”后，只复制和执行 BOM 子件、普通行和赠品行，订单直接变为已完成，不再停留部分出库。

## 3. 销退订单
1. 选择原发货单后，明细展示每一行的平摊单价和本次退货行总价。
2. 行总价 = 本次退货数量 × 原出库行平摊单价。
3. 销退汇总退货金额等于所有明细行总价合计。
4. 保存、编辑、提交时以后端原出库行价格重算金额，前端金额只用于展示。
5. 原发货单区域在编辑页和只读页均紧凑展示，不占用大块页面空间。
