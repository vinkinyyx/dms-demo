# DMS v4.0.0 需求规格

## 1. 租户能力开关
- 平台后台创建和编辑租户时，可配置是否启用进销存/库存。
- 关闭后隐藏并禁用采购订单、采退订单、仓库、供应商、库存查询、收货入库、库存移动、库存调整、盘点、效期预警、序列号追溯。
- 销售订单、销退订单、销售出库结果始终保留；销售出库结果只读。
- 关闭模块前校验不存在未完成采购、收货、库存移动、盘点、调整等单据；历史数据保留。
- 后端 API 必须进行能力校验，不能仅依赖菜单隐藏。

## 2. ERP 集成
- 销售订单审批通过后向 ERP 推送销售订单；销退订单审批通过后向 ERP 推送红字销售出库申请。
- ERP 接口先保留空实现，同时记录集成状态：待推送、推送成功、推送失败、取消待推送、取消成功、取消失败。
- 新增 ERP 回调接口，支持正向销售出库和红字销售出库结果，支持部分发货/部分红字出库。
- 回调接口必须幂等，支持 idempotencyKey 或 ERP 出库单号防重。
- 已提交或已审批但无任何出库结果的订单允许取消；取消时通知 ERP。
- 模拟发货按钮在所有租户显示，但通过权限控制；只生成出库结果，不扣减真实库存，并复用 ERP 回调入库逻辑。

## 3. 价格体系
- 一个 SKU 只有一个全局采购价。
- 采购订单不填写不含税价和税率，采购价格统一由价格主数据维护。
- 销售价维护不含税单价、税率，并按全局价和经销商价区分；经销商无专属价时回退全局价。
- 同一产品和经销商可以维护多条不同生效时间段价格，时间段不能重叠。
- 销售订单前端全部按含税金额展示，用户不需要感知税率。
- 订单提交时重新取最新有效价并快照；草稿保存时可展示当前估价，但提交以提交时价格为准。
- 经销商价和全局价都不存在时，不允许提交。

## 4. 销售订单
- 销售订单不选择出库仓库，仓库由销售出库子单确定。
- 编辑页有保存、提交、取消；列表只有查看/编辑、删除。
- 草稿可编辑、可删除；提交后不可删除；审批驳回后可重新编辑提交。
- 行折扣支持比例折扣和固定金额折扣；整单折扣也支持比例和固定金额。
- 折扣按含税口径录入；计算完成后重算不含税金额和税额。
- 行折扣、促销折扣、整单折扣叠加后，每一行和整单最终含税金额必须大于等于 0，否则拒绝提交并说明原因。
- 已提交或已审批但无出库结果可取消；有部分出库后不能整单取消，但可以关闭未发货 BOM 子件行。

## 5. 销退订单
- 销退必须基于销售出库子单创建，不直接基于销售订单头。
- 销退不支持折扣，退货价格取原销售订单子件行最终含税单价。
- 可退数量 = 已出库数量 - 已提交未取消销退占用数量 - 已红字出库数量。
- 提交即锁定可退数量；驳回、取消释放。
- 支持部分红字出库；已审批但无红字出库结果可以取消。
- 赠品 SKU 允许销退，单价为 0。
- 出库子单搜索支持经销商、出库日期范围、销售订单号、出库子单号、产品、批号/序列号、医院/终端、是否有可退数量。

## 6. 销售出库
- 一张销售订单可以对应多张销售出库子单。
- 一个销售出库子单只能有一个仓库。
- 启用库存的租户在发货时按仓库拆子单；关闭库存的租户由 ERP 回调创建子单。
- 销售出库结果菜单只读。
- BOM 子件允许分开发货，订单状态按子件聚合为部分出库或已完成。
- 未发货的 BOM 子件允许关闭，不影响已发货部分和退货。

## 7. 产品层次与 BOM
- 复用现有 product_lines 树形结构，承载产品层次1/2/3，最多三级。
- 产品增加产品层次关联；现有产品分类和产品类型不调整。
- 现有产品组合升级为 BOM，并增加版本管理；v4 只支持固定 BOM。
- BOM 母件为虚拟物料，不采购、不入库、不发货；采购只能选择 SKU。
- 订单保存 BOM 版本和子件快照，不自动切换最新版本。
- BOM 可维护全局价和经销商价；存在 BOM 价时按子件标准含税金额占比分摊到子件，无 BOM 价时按子件价合计。
- BOM 母件行不允许直接申请折扣，折扣作用于子件行。
- ERP 推送和回调展开为子件，同时携带 BOM 母件编码、版本和分组号。

## 8. 促销规则
- 促销支持满 A 赠 B、满 A 减钱。
- A 可以是特定 SKU，也可以是特定产品层次节点及其子节点下的 SKU，包含 BOM 展开后的子件。
- 满 A 赠 B 的赠品只能是 SKU，不允许是 BOM 母件。
- 满 A 赠 B 支持仅赠一次和每满 N 个循环赠送。
- 满 A 减钱支持比例折扣和固定金额折扣；固定金额按命中 A 行的金额占比分摊。
- 赠品行金额为 0，进入订单明细、出库结果，并允许以 0 元退货。
- 促销折扣允许与手工行折扣、整单折扣叠加。

## 9. 手术报台
- 所有租户解除可用库存限制。
- 批号、序列号支持手填、扫码、粘贴、导入。
- 序列号管理产品仍要求序列号，批次管理产品仍要求批号，但不校验库存是否存在。
- 手术报台只做植入/使用登记，不做库存扣减。
