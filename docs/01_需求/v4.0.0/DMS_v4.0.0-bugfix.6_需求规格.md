# DMS v4.0.0-bugfix.6 需求规格

## 1. 通用列表与详情
- 所有业务列表仅编号/编码字段作为链接；点击链接或“查看”进入只读页，只有“编辑”进入编辑态。
- 列表操作按钮超过 2 个折叠；已配置状态条件的记录必须显示“编辑/删除”等条件按钮。
- 关键词搜索支持按空格、英文逗号、中文逗号分隔多个值，每个值在核心编码、名称、规格等字段中模糊匹配。
- 新建抽屉必须铺满列表与筛选区域，且新建内容完全清空，不复用上一次表单数据。

## 2. 产品组合（BOM）
- active 版本显示“查看/新建版本”；draft 版本显示“查看/编辑/发布”。
- BOM 不提供删除按钮。
- 新建版本生成 draft 数据并直接打开该 draft 供编辑，原 active 版本保持不变；draft 头部母件信息不允许编辑。
- 版本号由系统生成，不允许用户手填。
- BOM 子件显示子件 SKU 编码/名称，不显示内部 ID。
- BOM 子件数量最少为 1，保存时前后端均校验。
- 按母件 SKU 编码排序不得报错。

## 3. 产品价格
- 价格类型只有“采购价/销售价”。
- 采购价只能维护单品，不允许选择 BOM 母件。
- 销售价必须选择经销商；选择 BOM 母件时自动展开当前 active BOM 的所有子件，逐个子件维护含税销售价、税率、不含税销售价。
- 含税销售价与税率可编辑；不含税价自动计算并保留 4 位小数。
- BOM 母件本身不维护销售价、不产生 0 元母件价格；同一 SKU、同一经销商、同一价格类型只允许一条有效价格。
- 价格创建后不可删除、不可编辑金额字段，只允许生效/失效和按有效期自动失效。
- 币种使用 CNY/USD 等字母编码，报表和相关展示带出币种。

## 4. 销售订单
- 新建销售订单必须清空历史表单；草稿/驳回状态显示编辑按钮，提交后不允许编辑或删除。
- 明细选择 BOM 母件后自动展开子件，母件为分组头，子件数量由母件数量和 BOM 配比计算，子件数量不可手改。
- 母件不维护价格、不打折；子件独立计价，行折扣按整行计算（例如 10 个、减 100 元，则整行减 100 元）。
- 整单折扣支持百分比和金额；百分比按折前金额比例计算并按金额占比分摊到每个计费行/EA。
- 编辑页和只读页均展示订单总价；订单总价由明细实时计算/后端持久化金额决定。
- 订单提交按钮只出现在编辑页，列表不展示提交按钮。
- 已审批订单可生成销售出库；已有出库数量时不允许取消，取消按钮不显示。
- 保存/提交不再做授权校验，不允许出现“商品无有效授权”类阻断。
- 连续保存/提交不得误报“请求正在处理中，请勿重复提交”。

## 5. 销退订单与销售出库
- 销退提交后状态进入待审批/自动审批，不再停留草稿。
- 审批完成的销退单可触发红字销售出库。
- 销售出库只读页/编辑页链接必须可正常打开，确认按钮不得跳转 404。
- 出库与销退链路传递订单行价格、母子件关联和红字/蓝字标识。

## 6. 操作日志
- 产品、BOM、价格、促销、销售订单、销退订单等只读页展示操作日志。
- 日志至少包含创建、编辑、提交、审批、驳回、取消、价格生效/失效、BOM 发布等关键动作。
