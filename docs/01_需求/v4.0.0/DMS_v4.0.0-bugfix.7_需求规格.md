# DMS v4.0.0-bugfix.7 需求规格

**版本**: v4.0.0-bugfix.7  
**日期**: 2026-08-20  
**测试环境**: http://43.128.145.141

## 1. 全局要求
1. 所有业务列表点击编号链接或“查看”进入只读页；只有点击“编辑”进入编辑页。
2. 列表行按钮超过 2 个时折叠；模块业务按钮配置优先于平台默认按钮配置。
3. 去除批量删除；新建表单必须清空历史状态。
4. 只读页必须展示操作日志。基础资料、订单、库存、营销、审批权限类页面统一只读体验。

## 2. 产品/BOM/价格
1. BOM 草稿显示“编辑”，active 显示“新建版本”；active 不允许直接编辑。
2. BOM 子件展示子件 SKU 编码和名称，不允许只显示 ID。
3. BOM 母件不维护销售价；销售价按经销商维护到每个子件，子件允许维护为 0。
4. 产品价格只允许生效/失效，不允许编辑或删除。
5. 采购价只能维护单品；销售价选择 BOM 母件时展开 active BOM 子件逐行维护。

## 3. 销售订单
1. 选择 BOM 母件后展开母件和子件；母件不打折，子件金额计入订单总价。
2. 母件可修改数量，子件数量按配比自动变化且不可手动修改。
3. 行折扣按整行计算，固定金额不按 EA 倍数放大。
4. 整单折扣按计费行折扣前余额比例平摊到每一行，BOM 母件不作为分摊基数。
5. 订单保存、提交、取消、生成销售出库按钮按状态和已出库数量显示。

## 4. 出库与销退
1. 销售出库只读页展示订单信息、发货汇总、已发货记录和操作记录。
2. 销退仅能选择存在可退数量的出库单；退货数量必须为整数。
3. 销退继承原订单/出库单价格，提交后进入审批中。
4. 审批通过的销退单可生成红字销售出库。
5. 销退、采退的创建、提交、审批、取消均记录操作日志。

## 5. 促销与币种
1. 促销规则只能启用/停用，不允许删除。
2. 满 A 赠 B 与满 A 减钱按模式显示不同必填字段；折扣只在订单层体现。
3. 币种展示使用 CNY、USD 等字母编码；汇率维护本期不参与计算。
