# 开发环境启动手册

## 1. 环境要求

本地开发至少准备：

- JDK 17，推荐 Temurin 或 Adoptium。
- Maven 3.9+；如果使用 Docker 构建，可以不装 Maven。
- Node.js 18+ 和 npm。
- PostgreSQL 14+。
- Redis 6+。
- MinIO（如需要文件上传、合同 PDF、附件功能）。
- Docker Desktop（可选，但推荐用于启动依赖服务）。

## 2. 获取代码

```powershell
git clone <仓库地址> DMS
cd DMS
```

目录说明：

- `backend/`：后端服务。
- `frontend-vue/`：业务前端。
- `admin-vue/`：平台后台。
- `docs/`：历史设计和交接文档。

## 3. 准备数据库

如果本地已经安装 PostgreSQL，可创建数据库：

```sql
CREATE DATABASE dms;
CREATE USER dms WITH PASSWORD 'dms123456';
GRANT ALL PRIVILEGES ON DATABASE dms TO dms;
```

本地配置位于：

- `backend/src/main/resources/application-local.yml`

该 profile 默认连接：

- PostgreSQL：`localhost:5432/dms`
- 用户名：`dms`
- 密码：`dms123456`
- Redis：`localhost:6379`
- MinIO：`http://localhost:9000`

如果本地账号、端口或密码不同，不要直接改通用配置，建议通过环境变量覆盖，或创建不提交的本地 profile。

## 4. 启动后端

### 方式 A：本地 Maven 启动

```powershell
cd backend
mvn clean package -DskipTests
mvn spring-boot:run -Dspring-boot.run.profiles=local
```

启动后验证：

- API 服务：`http://localhost:8080`
- Swagger：`http://localhost:8080/swagger-ui.html`
- 健康检查：`http://localhost:8080/actuator/health`

### 方式 B：Docker 构建后端

后端目录存在以下 Dockerfile：

- `backend/Dockerfile`
- `backend/Dockerfile.aliyun`
- `backend/Dockerfile.runtime`

可先构建镜像：

```powershell
cd backend
docker build -t dms-backend:local .
```

运行容器时必须传入数据库、Redis、MinIO 和 JWT 相关环境变量。仓库中未找到可直接使用的 `docker-compose.yml`，不要假设 `docker compose up -d` 当前一定可用。

## 5. 启动业务前端

```powershell
cd frontend-vue
npm install
npm run dev
```

默认访问：

- `http://localhost:5173`

Vite 会把以下路径代理到 `http://localhost:8080`：

- `/api`
- `/auth`

如果后端不在本机 8080，可设置：

```powershell
$env:VITE_API_TARGET="http://后端地址:端口"
npm run dev
```

## 6. 启动平台后台

```powershell
cd admin-vue
npm install
npm run dev
```

默认访问：

- `http://localhost:5174/admin/`

平台后台的 Vite `base` 是 `/admin/`，访问时不要漏掉尾部路径。

## 7. 默认账号

历史文档记录的默认管理员账号：

```text
admin / Sh123456
```

首次登录可能强制修改密码。本地或测试环境如果无法登录，优先检查：

- 数据库是否执行过迁移或 seed。
- 后端连接的是否为目标数据库。
- 当前账号是否被禁用或要求改密。
- Redis 中是否残留旧 Token 或登录状态。

## 9. 本地启动验收

本地环境跑通的最低标准：

- 后端 `/actuator/health` 返回 UP。
- 能打开 Swagger。
- 业务前端能显示登录页。
- 平台后台能显示登录页。
- 使用有效账号能登录业务端。
- 使用后台账号能进入平台后台。
- 至少完成一次列表查询和一次详情打开。
- 如涉及文件功能，至少完成一次上传或下载验证。

## 10. 常见启动问题

### Maven 命令找不到

安装 Maven，或使用 Docker 方式构建。

### 数据库连接失败

检查：

- PostgreSQL 是否启动。
- `dms` 数据库是否存在。
- 用户名密码是否匹配。
- 后端 profile 是否为 `local`。

### Flyway 迁移失败

检查：

- 迁移脚本版本是否重复。
- 数据库用户是否有权限建表、改表。
- 是否在已有生产库上执行了未验证脚本。
- 失败后 `flyway_schema_history` 中的失败记录是否已处理。

### 前端接口 404 或跨域

检查：

- 后端是否在 8080 启动。
- `VITE_API_TARGET` 是否设置正确。
- Nginx 是否把 `/api`、`/auth`、`/actuator` 代理到后端。

### 登录后立即掉线

检查：

- JWT 密钥是否变化。
- 后端时间和前端时间是否偏差过大。
- Redis 是否清空了会话相关 key。
- 账号状态、租户状态、密码修改状态是否正常。
