# 订单折扣与促销规则说明书（v4.3.0）

> 销售订单计价、促销、代金券的唯一业务口径。前端预览、后端落库、退货计价均以此为准。
> 全部为含税金额；数量为正整数；单价/金额精确到分（2 位小数），中间用高精度，尾差最后统一吸收。

## 1. 名词定义

- 基础价 basePrice：单个 EA 含税单价，取价优先级 合同价 > 客户基础价 > 全局价。
- 行标准金额 standardAmount = basePrice × qty。
- 产品全局折扣：产品维度自动折扣比例（只减）。
- 促销：满减、满赠、满 N 件打折（作用于 SKU 或品类，同 SKU 同时段唯一）。
- 行手动折扣：行上人工输入，支持百分比/金额、加/减两个方向。
- 行金额 lineAmount：行级折扣处理完后的含税金额。
- 客户全局折扣：客户维度自动折扣比例（只减），作用整单后摊回行。
- 整单手动折扣：整单人工输入，支持百分比/金额、加/减，摊到行与 EA。
- 一口价 FIXED_PRICE：整单指定成交价，产品按基础原价，差额摊到行。
- 0 金额：整单 0（ZERO_ORDER）或某行手动 0（lineZero）。
- 代金券 VOUCHER：整单层抵扣，不摊入任何行单价。
- 赠品行 isGift：促销赠送，金额恒 0，不参与任何整单分摊。

## 2. 计价优先级（标准模式 NORMAL）

行级（逐行）：
1. 取基础价 basePrice（记录 priceSource）。
2. 产品全局折扣：productDiscountAmount = standardAmount × 产品折扣率。
3. 产品促销折扣：满 N 打折（百分比或固定单价）/满减金额，记录 promoType/promoHitId 与文案。
4. 行手动折扣：按 lineDiscountType(PERCENT/AMOUNT) 与方向(+/-) 计算。
5. 得出行金额 lineAmount = standardAmount − 产品折扣 − 促销折扣 −/＋ 行手动折扣。

整单级（所有行 lineAmount 算出后）：
6. 客户全局折扣：按各行 lineAmount 占比摊回每行。
7. 整单手动折扣：按各行 lineAmount 占比分摊（减或加）。
8. 行最终金额 finalAmount 落定，再分摊到 EA 单价：unitPriceInclTax = finalAmount / qty，2 位小数，尾差落在金额最大行的最后一 EA。
9. 按各行税率反算不含税金额与税额。

约束：
- 任何一行 finalAmount 不得小于 0；整单 finalAmount 不得小于 0；违反则整单拦截并提示具体行/原因。
- 行手动折扣“减”不得使该行小于 0；整单“减”分摊后任一非 0 行小于 0 也拦截。
- 手动 0 金额行 lineAmount=0、权重 0，低开与高开都不向其分摊。
- 加价（高开）无上限，不需要原因。

## 3. 促销规则

### 3.1 类型
- QTY_DISCOUNT：SKU 或品类满 N 件，对该批享折扣（PERCENT 百分比 / FIXED_PRICE 固定单价）。
- QTY_REDUCE：SKU 或品类满 N 件，减固定金额。
- GIFT：SKU 或品类满 N 件赠送赠品（支持每满 N 循环 EVERY_N）。

### 3.2 门槛与命中
- 门槛数量按同 SKU 合并计算；若同 SKU 被拆多行提交，后端拦截：“SKU[xxx] 存在重复行，请合并为一行后提交”。
- “满 N 件打折”命中后，该行不允许再使用行手动折扣（UI 禁用+后端校验）。
- 满减/满赠命中行仍可叠加行手动折扣。
- 处于促销中的 SKU 不允许手动设为 0 金额。
- 赠品行 isGift，单价/金额 0，不参与整单加减分摊。

### 3.3 唯一性
- 同一 SKU 在同一有效时间段只能命中一种促销。
- 保存/审批时把 SKU/品类展开为 SKU 集合，校验时间窗交集；冲突则拦截并列出冲突活动名称与时间段。

### 3.4 退货与促销
- 退货导致不满足门槛时：赠品可按 0 金额退回；已享受优惠从退款中相应扣减。

## 4. 互斥模式与矩阵

### 4.1 互斥模式（与 NORMAL 互斥，只能选一）
- FIXED_PRICE 一口价：产品按基础原价（不走任何折扣），差额按行金额占比摊到行与 EA。
- ZERO_ORDER 整单 0：所有行金额 0。
- VOUCHER 代金券：产品按基础原价，整单层用券抵扣，券额不计入行单价。

一口价、整单 0、代金券两两互斥；使用其一则产品折扣、促销、行折扣、客户折扣、整单折扣全部不可用。

### 4.2 行 0 金额（lineZero）在 NORMAL 下
- 该行产品全局折扣、促销折扣、行手动折扣不可用。
- 客户折扣/整单折扣：低开（减）对该行不生效（权重 0）；高开（加）同样因权重 0 不分摊到该行。

## 5. 代金券

- 厂家统一发放；销售或客户下单均可使用；一单仅一张。
- 含面值、有效期、范围（全场/产品/品类）、最低消费门槛。
- 校验：有效期内、范围命中、满足门槛、未使用/未作废、面值 ≤ 订单基础原价合计（否则拦截，不找零不超额）。
- 抵扣额只记订单 voucherAmount，不回写任何行单价/EA 单价（防退货套现）。
- 退货：用券订单按基础原价 EA 退货退款，不退还券抵扣；部分退货不退券。
- 整单未出库作废返还券；已出库或部分出库不退券。

## 6. 退货计价（关联 R1）

- 折扣/一口价订单：按分摊后的 EA 单价退款。
- 代金券订单：按基础原价 EA 单价退款，券抵扣不退。
- 多张出库单合并退：EA 单价按各来源出库单快照分别取，不跨单平均。
- 部分退货：退货金额 = 退货数量 × EA 单价；最后一次退货吸收尾差。
- 促销单退货：赠品按 0 退，已享优惠按规则扣减。

## 7. 数量与 BOM

- 销售订单/销退/销售出库数量均为正整数；小数、0、负数前后端均拦截。
- BOM 子件用量必须为正整数；母件数量 × 子件用量 = 整数。
- 同 SKU 多行在促销校验时拦截合并。

## 8. 促销文案

- 订单顶部文本列举全部命中促销，例如：
  - “本单满足【满10件9折】：产品 A（PRD-001）10 件，享 9 折，优惠 ¥120.00”
  - “本单满足【满赠】：买 A 满 5 件，赠送 B ×2”
- 每行展示命中促销名称与该行优惠金额。
- 文案与命中落库 order_promotion_hits / orders.promo_messages，详情与打印可见。

## 9. 校验与错误提示

- 提交期任何校验失败必须阻断并给出具体原因，至少含行号/SKU、违反规则、建议动作。
- 示例：
  - "第 3 行[A 产品]：整单折扣后金额小于 0，请减少整单减额。"
  - "SKU[PRD-001] 在 2026-09-01~2026-09-30 已存在促销【中秋满减】，不可重复配置。"
  - "同一 SKU[A 产品] 存在两行，请合并为一行后提交。"
  - "代金券面值 ¥500 大于商品合计 ¥430，不可使用。"

## 10. 折扣组合测试场景集（验收用）

每场景均覆盖：前端真实点击 + 后端 API 直算 + DB 回读 + 业务规则 + 异常路径，并验证反向操作顺序与重复提交。

### A. 基础计价
- A1 单行无折扣：basePrice×qty=行=整单。
- A2 多行无折扣合计正确。
- A3 多税率行税额独立、整单税额=各行之和。
- A4 数量为 0/负/小数：前后端拦截。

### B. 行手动折扣（含加价）
- B1 行折扣百分比减。
- B2 行折扣金额减。
- B3 行折扣百分比加（高开）。
- B4 行折扣金额加（高开）。
- B5 行减额 ≥ 行金额 → 拦截（不能 <0）。
- B6 多行混合加减。
- B7 反向顺序：先折扣后改数量 / 先改数量后折扣，结果一致。

### C. 产品全局折扣
- C1 命中：basePrice×(1−折扣率)。
- C2 产品折扣 + 行手动折扣（顺序 2→4）。
- C3 未生效/过期不应用。
- C4 同产品时间段重叠配置 → 保存拦截。

### D. 促销
- D1 单品满 N 件打折（百分比），命中/未命中。
- D2 单品满 N 件固定单价。
- D3 品类满 N 件打折。
- D4 满 N 件减金额。
- D5 满赠：赠品行金额 0、不参与整单分摊。
- D6 同 SKU 同时段两条促销 → 配置拦截。
- D7 促销 SKU 手动设 0 → 拦截。
- D8 QTY_DISCOUNT 命中行：行手动折扣禁用。
- D9 满减/满赠行仍可叠加行手动折扣。
- D10 同 SKU 拆多行 → 提交拦截要求合并。
- D11 顶部文案 + 行标签 + order_promotion_hits 落库。
- D12 退货跌破门槛：赠品 0 退、已享优惠扣减。

### E. 客户全局折扣
- E1 按折后行金额占比摊到每行。
- E2 与产品折扣/促销/行折扣叠加（顺序 2/3/4→客户折扣）。
- E3 含 0 行：0 行不摊减。
- E4 摊后任一行 <0 → 拦截。
- E5 过期/停用不生效；同客户时间段重叠拦截。

### F. 整单手动折扣 / 一口价 / 整单 0
- F1 整单减 %：摊到行/EA，尾差落最大行。
- F2 整单减金额：按行金额占比分摊。
- F3 整单加 %/加金额：按行金额占比摊（0 行权重 0，不摊）。
- F4 整单减导致某行 <0 → 拦截。
- F5 一口价：差额按行金额占比摊，合计=一口价；全部按基础原价。
- F6 整单 0：所有行 0。
- F7 一口价与任意折扣/券互斥（UI 禁用+后端校验）。
- F8 行 0 + 整单低开：0 行不摊减。
- F9 行 0 + 整单高开：0 行权重 0，不分摊加价。

### G. 代金券
- G1 抵扣整单，DB 回读行 unitPrice 仍为基础原价。
- G2 面值 > 原价合计 → 拦截。
- G3 过期/停用/他人券不可选。
- G4 券与任意折扣互斥；与一口价/整单 0 互斥。
- G5 用券后整单=原价合计−券面，税额正确。
- G6 一单一张、重复提交不重复核销。
- G7 部分退货按基础原价 EA 退、不退券；整单未出库作废返还券。
- G8 范围/最低消费门槛校验。

### H. 互斥矩阵
- H1 行 0：禁用产品折扣/促销/行折扣；客户/整单低开不摊该行。
- H2 促销 SKU 不可设 0。
- H3 一口价/代金券/整单 0：强制原价、禁用全部折扣，三者互斥。
- H4 自动折扣不可手动关闭。
- H5 赠品行不参与任何整单加减分摊。

### I. 精度、尾差、退货
- I1 多行分摊尾差落最大行，合计精确到分。
- I2 EA 单价：尾差落最大行最后一 EA。
- I3 部分退货按 EA 单价退，最后一次吞尾差。
- I4 折扣/一口价单退货按摊后 EA 退。
- I5 用券单退货按基础原价 EA 退、不退券。
- I6 一张销退单关联多张出库单：各单可退量独立锁定、分别回写。
- I7 含税口径退货金额/税额回算正确。

### J. 权限与客户账号
- J1 客户仅见自己的订单/地址/券/合同/报表/授权/手术报台。
- J2 越权 API 返回 403/空。
- J3 销售可为自己及下级负责客户下单，不能为无权限客户下单。
- J4 客户注册→待审核→通过自动激活账号+dealer；驳回可改重提。
- J5 客户 H5 下单全流程：选地址、选品、自动折扣、选券、一口价、提交、查看。

### K. 移动端 H5
- K1 客户自助下单折扣/券/地址全部可用，无 Console 红错、无 4xx/5xx。
- K2 促销文案在订单确认页完整展示。
- K3 注册页资料 + 附件上传。
- K4 我的订单/销退申请/手术报台可用。

### L. 核心流回归（F1–F5）
- F1 下单→审批→出库→库存扣减。
- F2 销退→选出库单→可退量锁定→回写。
- F3 采购→收货→入库。
- F4 BOM + 促销 + 下单计价。
- F5 审批流：提交→通过/驳回→状态回读（含 approval_node_assignees 非空）。
