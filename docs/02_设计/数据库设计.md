### V140 新增表 `cross_tenant_doc_links` — 跨租户单据关联台账（溯源 + 幂等）
| 列 | 类型 | 说明 |
|----|------|------|
| id | BIGSERIAL PK | |
| manufacturer_tenant_id | UUID NOT NULL | 厂家租户 |
| dealer_tenant_id | UUID NOT NULL | 经销商租户 |
| link_type | VARCHAR(24) | `PO_TO_SALES_ORDER`（采购转销售）/ `SALES_OUT_TO_RECEIPT`（出库转收货） |
| po_id / po_code | BIGINT / VARCHAR(64) | 经销商采购订单 id/号 |
| sales_order_id / sales_order_code | BIGINT / VARCHAR(64) | 厂家销售订单 id/号 |
| sales_out_id / sales_out_code | BIGINT / VARCHAR(64) | 厂家销售出库 id/号 |
| receipt_id / receipt_code | BIGINT / VARCHAR(64) | 经销商收货入库 id/号 |
| line_refs | JSONB DEFAULT '[]' | 行级溯源：厂家/经销商产品编码、qty、batchNo、serialNo、poLineId/poSeq 等 |
| status | VARCHAR(16) DEFAULT 'linked' | |
| created_at / updated_at | TIMESTAMPTZ | |

唯一/索引：
- `ux_ctdl_sales_out (sales_out_id) WHERE sales_out_id IS NOT NULL` —— 一张厂家出库单只回传一次（幂等）。
- `ux_ctdl_po (po_id) WHERE po_id IS NOT NULL AND link_type='PO_TO_SALES_ORDER'` —— 一张采购单只转一张销售单。
- `idx_ctdl_dealer (dealer_tenant_id, link_type)`。

### V140 新增/变更列
| 表 | 列 | 类型 | 说明 |
|----|----|------|------|
| `suppliers` | `manufacturer_tenant_id` | UUID REFERENCES tenants(id) | 非空即"平台厂家"系统供应商，指向厂家租户；经销商采购单选它才触发跨租户。部分索引 `idx_suppliers_mfr`。 |
| `purchase_orders` | `vendor_order_code` | VARCHAR(64) | 回写：转换生成的厂家销售订单号。索引 `idx_po_vendor_code`。 |

| `tenants` | `modules_enabled`(jsonb，已有列) | — | V140 对所有 `tenant_type='MANUFACTURER'` 写入 `inventoryEnabled:false, purchaseEnabled:false`（厂家默认关闭进销存，重建库不复发）；经销商租户不动。 |

### V140 数据补录
- 为每个 `tenant_type='DEALER' AND owner_manufacturer_id IS NOT NULL` 且尚无平台厂家供应商的经销商租户，插入一条 `suppliers(code='PLATFORM_MFR', manufacturer_tenant_id=归属厂家)`。

### 复用既有表（无结构变更）
- 厂家销售订单：`orders`(order_type=NORMAL) + `order_lines`；厂家出库：`sales_outs` + `sales_out_lines`（批次/序列号在 `sales_out_lines.batch_no/serial_no`）。
- 经销商采购：`purchase_orders` + `purchase_order_lines`；收货：`receipts`(ref_doc_type='sales_out', source_po_id) + `receipt_lines`（批次/序列号 `batch_no/serial_no`，expected_qty/received_qty）。
- 对码：`product_mappings`（manufacturer/dealer 双侧 product_id+code、conversion_rate、status）；绑定：`tenant_dealer_bindings`。

| remark | VARCHAR(512) | 备注 |
| request_body | TEXT | 请求体JSON（敏感字段已脱敏） |
| response | TEXT | 响应体JSON |
| stack | TEXT | 异常堆栈 |
| created_at | TIMESTAMPTZ | 创建时间 |

**索引**：
- `idx_oplog_request_id (request_id)`：按请求ID查询全链路
- `idx_oplog_layer (layer)`：按层级筛选
- `idx_oplog_created_at (created_at DESC)`：按时间排序
- `idx_oplog_tenant_id (tenant_id)`：按租户筛选
- `idx_oplog_user_id (user_id)`：按用户筛选

**敏感字段脱敏规则**：
- 自动识别 `password`、`pwd`、`secret`、`token`、`key` 等字段
- 值替换为 `***`，避免密码等敏感信息泄露
