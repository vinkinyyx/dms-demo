### V27 新增 op_log 表 — 全链路操作日志

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGSERIAL | 主键 |
| request_id | VARCHAR(64) | 请求链路ID，UUID |
| layer | VARCHAR(32) | 层级: HTTP-IN（请求进入）/ HTTP-OUT（响应返回）/ BUSINESS（业务层）/ EXCEPTION（异常） |
| http_method | VARCHAR(16) | HTTP方法: GET/POST/PUT/DELETE等 |
| path | VARCHAR(512) | 请求路径 |
| status | INTEGER | HTTP状态码 |
| spent_ms | BIGINT | 耗时（毫秒） |
| user_id | BIGINT | 操作用户ID |
| username | VARCHAR(64) | 操作用户名 |
| tenant_id | UUID | 租户ID |
| ip | VARCHAR(64) | 客户端IP |

| biz_type | VARCHAR(64) | 业务类型 |
| biz_id | VARCHAR(64) | 业务ID |
| action | VARCHAR(32) | 操作类型: CREATE/UPDATE/DELETE等 |
| remark | VARCHAR(512) | 备注 |
| request_body | TEXT | 请求体JSON（敏感字段已脱敏） |
| response | TEXT | 响应体JSON |
| stack | TEXT | 异常堆栈 |
| created_at | TIMESTAMPTZ | 创建时间 |

**索引**：
- `idx_oplog_request_id (request_id)`：按请求ID查询全链路
- `idx_oplog_layer (layer)`：按层级筛选
- `idx_oplog_created_at (created_at DESC)`：按时间排序
- `idx_oplog_tenant_id (tenant_id)`：按租户筛选
- `idx_oplog_user_id (user_id)`：按用户筛选

**敏感字段脱敏规则**：
- 自动识别 `password`、`pwd`、`secret`、`token`、`key` 等字段
- 值替换为 `***`，避免密码等敏感信息泄露
