# DMS v4.4.0 总体设计

> 版本：v4.4.0（MINOR）  日期：2026-08-28  基线：v4.3.2
> 需求：`docs/01_需求/v4.4.0/DMS_v4.4.0_需求规格.md`

## 1. 数据模型（Flyway V136 / V137）

### 1.1 经销商寄售/资信字段（dealers 扩展）
- consignment_enabled boolean：是否开启寄售库存（补货/开票订单门禁）。
- consignment_limit numeric：寄售额度；credit_limit numeric：信用额度；payment_days int：账期。
- settlement_method、credit_grade：结算方式、信用等级。

### 1.2 consignment_stock（寄售库存台账）
唯一维度：tenant_id + dealer_id + product_id + batch_no + serial_no（部分唯一索引，deleted_at IS NULL）。
- on_hand_qty 在库量；locked_qty 开票预占量；std_unit_price 标准单价；warehouse_id；source_sales_out_id。
- 可用量 = on_hand_qty - locked_qty。

### 1.3 consignment_stock_movements（寄售流水）
- change_type：REPLENISH_IN（补货入库）、INVOICE_LOCK（开票预占）、INVOICE_DEDUCT（审批通过实扣）、INVOICE_RELEASE（拒绝/退回/撤回释放）。
- qty_change 带符号；ref_type=SALES_OUT/INVOICE_ORDER，ref_id/ref_code 关联单据。

### 1.4 dealer_credit_profiles（经销商资信运行期）
- 唯一：tenant_id + dealer_id（部分唯一索引）。
- credit_used 信用占用（占位，应收未集成）、consignment_used 寄售占用 = SUM(on_hand_qty * std_unit_price)。
- over_limit_action 默认 APPROVAL（超额/超账期触发审批，不硬拦截）。

### 1.5 orders / order_lines 扩展
- orders.order_type：SALES / REPLENISHMENT / INVOICE / SAMPLE / CUSTOM。
- orders.terminal_hospital_id/name：开票结算终端（终端医院）；orders.sample_reason：样品申请原因。
- order_lines.batch_no、order_lines.serial_no：开票行携带批号/序列号（NOT NULL 约束 line_zero 等沿用）。

### 1.6 审批模板
- V137 为 default 租户播种 INVOICE_ORDER 人工审批模板（与 V135 RMA_ORDER 同构），使开票订单提交后进入审批中心。

## 2. 订单类型计价规则（V4OrderService.calculate）
- REPLENISHMENT：所有行 lineZero=true、清空行/整单折扣、voucherId=null、pricingMode=NORMAL、fixedPrice=null、applyPromotions=false；校验经销商寄售开关。
- SAMPLE：非 CHILD 行计数必须为 1，sampleReason 必填；同样清零折扣/促销/代金券。
- INVOICE：voucherId=null、pricingMode=NORMAL、fixedPrice=null、lineZero=false、applyPromotions=false（不参与满减/满赠；产品促销/经销商折扣/行/整单折扣仍由引擎按合同/客户/全局价计算）；校验寄售开关 + validateInvoiceConsignment。
- CUSTOM：保留，按普通订单。

## 3. 寄售库存服务（com.dms.consignment）
- ConsignmentService：
  - onReplenishShipped(dealerId, salesOutId, lines)：补货发货后 on_hand+（upsertStock，REPLENISH_IN 流水），由销售出库发货在源订单为补货时触发。
  - lockForInvoice：提交开票时逐行校验可用量并 locked+（INVOICE_LOCK），不足抛业务异常（带产品编码+名称）。
  - deductForInvoice：审批通过 on_hand- 且 locked-（INVOICE_DEDUCT）。
  - releaseForInvoice：拒绝/退回/撤回 locked-（INVOICE_RELEASE）。
  - availableForInvoice(dealerId, keyword)：返回可用量>0 的台账（产品编码/名称/规格/批号/序列号/仓库/可用量/标准单价/金额），供选择器。
  - recomputeConsignmentUsed：按标准价汇总在库金额，UPSERT dealer_credit_profiles.consignment_used（ON CONFLICT (tenant_id,dealer_id) WHERE deleted_at IS NULL）。
- InvoiceOrderApprovalCallback（businessType=INVOICE_ORDER）：onApproved→deduct；onRejected/onReturned/onWithdrawn/onTerminated→release。行数据从 order_lines 读取（product_id/batch_no/serial_no/qty；order_lines 无 warehouse_id，仓库以台账为准）。

## 4. 开票寄售库存选择器（前端 OrderCreate.vue）
- 订单类型为 INVOICE 时，明细区显示「选择寄售库存」按钮（替代普通添加行）；产品单元格为禁用 ResourcePicker + 批号/序列号 el-tag。
- 弹窗 `/api/consignment/available`：经销商只读展示，关键字检索，el-table 多选（row-key=ck，reserve-selection），每行 el-input-number 本次开票数量（max=可用量）。
- 确认后按 产品+批号+序列号 合并，整单替换 form.lines（makeLine 携带 batchNo/serialNo/stockId），触发计价预览。
- 计价/保存 payload 行携带 batchNo/serialNo；预览回写保留这两个字段。
- INVOICE/REPLENISHMENT/SAMPLE/CUSTOM 锁定计价方式为 NORMAL（pricingLocked），隐藏代金券/一口价/0金额入口。

## 5. 进销存租户开关精细化
- 后端 TenantFeatureGuard：requireInventory()/requirePurchase() 对**经销商用户**（DataScope.currentUser().dealerId() 非空）直接放行；仅对厂家用户在 tenants.modules_enabled.inventoryEnabled=false 时抛「当前租户未启用进销存/库存模块」。采购/库存/收货/移动/调整/盘点等接口加守卫。
- 前端 layout/index.vue：isVendor 且 features.inventoryEnabled=false 时过滤 inventoryOnly/purchaseOnly 菜单项；销售/销退/出库/寄售库存不带该标记，始终保留。features 来自 GET /api/tenant/features。

## 6. 接口
- GET /api/consignment/available?dealerId=&keyword=：开票选库存。
- GET /api/dealer-credit：经销商资信与账期列表。
- GET /api/tenant/features：当前租户功能开关（inventoryEnabled/purchaseEnabled）。
- 订单预览/创建/提交沿用 /api/sales-orders(/preview、/{id}/submit)，按 order_type 分支。

## 7. 关键修复（本次联调发现）
- productLabel/产品名查询引用了 products 不存在的 name 列（仅 name_cn），导致开票预览 500——改为 COALESCE(name_cn,...)。
- order_lines INSERT 增加 batch_no/serial_no 列后参数顺序错位（line_zero 绑定到 batch_no，line_zero 落 null 违反 NOT NULL）——重排为 ?38=batch_no、?39=serial_no、?40=line_zero。
- 开票回调/提交处从 order_lines 读取 warehouse_id（该表无此列，Tuple alias 报错）——移除，仓库以台账为准。
- recomputeConsignmentUsed 的 INSERT 未绑定参数且 ON CONFLICT 无目标（部分唯一索引无法推断）——补绑定并指定 ON CONFLICT (tenant_id,dealer_id) WHERE deleted_at IS NULL。
- 开票产品禁用 ResourcePicker 缺 resource 属性导致 /api/lookups/undefined 404；寄售选择表 row-key 需设在 el-table 上（reserve-selection 要求）。
