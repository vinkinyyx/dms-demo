## 用户需求

| # | 需求 | 覆盖 |
|---|------|------|
| 1 | 收货完成/取消 → 收货单 + PO 同步 COMPLETED (非 RECEIVING) | ReceiptBatchService.syncPoStatus + cancelRemaining |
| 2 | PO 列表去除 `总金额`; `审核人` 从 users 表回填 | PurchaseOrderController list SQL + toBrief + modules.js |
| 3 | PO 取消时对应收货单同步关闭 (含子单) | PurchaseOrderController.cancel() 级联 UPDATE receipts + receipt_batches |
| 4 | 收货单号 `RK-*` → `GR-YYYYMMDD-N`, 子单 `GR-*-M`; 销售出库 `CK/SO-*` → `GI-YYYYMMDD-N` | DocNoGenerator prefix 全面切换 |
| 5 | 收货列表去除 `仓库ID` `源类型`; 详情/编辑页最下方加操作记录 | modules.js receipts cols + ReceiptEdit.vue 操作记录卡片 |
| 6 | 子单确认收货时记 `confirmed_at` 作入库时间, 页面展示 | ReceiptBatchService.confirm 写 confirmed_at, ReceiptEdit 卡片展示 |

## 关键改动

### 后端 (Java)
- `DocNoGenerator.next("PREFIX")` 调用点更新:
  - `ReceiptService`: RK → GR
  - `AutoDocGenerator`: RK/RRK → GR/GRR; CK/RCK → GI/GIR
  - `SalesOutService`: CK → GI
  - `OrderApprovalExecutionController` / `SalesOutOpsController`: `(isRed?SR:SO)-timestamp` → `docNoGenerator.next(isRed?GIR:GI)` (需要注入 DocNoGenerator bean)
- `PurchaseOrderController.cancel()`:
  - 级联 `UPDATE receipts SET status='CANCELLED'` (DRAFT/RECEIVING/PARTIAL_RECEIVED/APPROVED)
  - 级联 `UPDATE receipt_batches SET status='CANCELLED', cancel_reason='源 PO 已取消'`
- `PurchaseOrderController` list SQL: LEFT JOIN users u ON u.id = po.approved_by, 取 u.name AS audit_user_name, po.approved_at AS audit_at → toBrief 输出 `auditUserName / auditAt`
- `ReceiptBatchService.syncPoStatus`:
  - 新增开头判断: 若源 PO 的所有 receipts 均已终结 (COMPLETED/CANCELLED), PO 转 COMPLETED
- `ReceiptBatchService.cancelRemaining`:
  - 尾部级联: source_po_id 关联 PO 若还在 APPROVED/RECEIVING → COMPLETED (completed_at = now())
- `ReceiptBatchService`:
  - createBatch/updateBatchLines/confirmBatch/cancelBatch 返回 res 均加 `receiptId` 字段 (供 @OperationLog 聚合)
- `OperationLogAspect.tryExtractIdFromResult`: Map 结果优先取 `receiptId`, 无则回退 `id`
- `OperationLogAspect.logAround`: 改为 **优先** 从 result 提取 businessId, fallback 到方法参数 (对 UPDATE 也生效)

### 前端 (Vue)
- `modules.js` 采购订单:
  - cols 去除 `totalAmount`; 已有 `auditUserName` 列 (无需新增, 后端字段现已提供)
- `modules.js` 收货入库:
  - cols 去除 `warehouseId` (仓库ID), `refDocType` (源类型)
- `ReceiptEdit.vue`:
  - 页面底部新增 `操作记录` 卡片, 表格列 时间/操作人/操作/备注
  - `loadOpLogs()` 调 `/api/operation-log/list/receipt/{id}`
  - onMounted + 4 处 `await loadReceipt(); await loadOpLogs()` 保持刷新
