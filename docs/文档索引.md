## 七、整理规则（2026-09-02 更新）

1. 需求类日常变更只追加 `01_需求/DMS需求文档_汇总版.md`；大版本需求规格归档到 `01_需求/<版本号>/`；
2. 设计类按 9 个子主题各保留**一份主 md**（业务功能/数据库/API/审批流/平台后台/UI/运维部署/测试策略/部署报告），评审报告放 `02_设计/reviews/`，大版本专版放 `02_设计/<版本号>/`；
3. 接口文档统一放 `03_接口文档/`：内部全量清单看 `内部API清单.md`（随 Controller 变更同步），对外/HMAC 接口一份接口一份 md 或 docx；
4. 测试类保留**场景案例 + 步骤各一份主文档**，**每次测试一份独立报告**放 `04_测试/` 根，版本过程材料归档到 `04_测试/<版本号>/`；
5. 汇总索引类保留在 docs 根目录；接管运维手册放 `05_接管运维/`；
