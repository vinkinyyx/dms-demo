### 6. 发现的问题与缺口

#### P0 阻断问题

1. **测试环境平台后台页面 500**
   - 现象：`http://8.133.193.238:8083/admin/` 和 `/admin/index.html` 均返回 HTTP 500。
   - 影响：测试环境无法打开平台后台 UI；虽然平台 API 可通过 8082 直连验证，但普通验收路径不可用。
   - 对比：生产 `:8081/admin/` 返回 200，说明测试环境 admin dist 或 nginx 配置异常。

2. **`GET /api/admin/tenant-admins` 返回 500**
   - 现象：平台后台“租户管理员”页面无法加载已有管理员列表。
   - 根因：`AdminTenantAdminController` 只实现了创建、停用、重置密码，没有 GET 列表接口；前端 `TenantAdmins.vue` 目前只有操作表单，没有列表展示，但请求该接口会触发 500。
   - 影响：租户管理员管理能力不完整，无法查看/检索现有管理员。

#### P1 重要问题

3. **产品分类树、区域树接口 500**
   - 现象：`GET /api/product-categories/tree`、`GET /api/regions/tree` 返回 500。
   - 代码事实：当前 `ProductCategoryController` 和 `RegionController` 未实现 `/tree` 接口；如果前端或旧配置调用该路径，会产生异常日志。
   - 影响：树形筛选/层级展示存在潜在断点；普通分页列表可正常使用。

4. **平台后台报表总览未真正接入数据**
   - 现象：`admin-vue/src/views/reports/Overview.vue` 调用 `/api/admin/tenants/stats` 和 `/api/admin/tenants`。
   - 问题：后端没有 `/api/admin/tenants/stats`，且 `/api/admin/tenants` 是 404，真实列表接口是 `/manufacturers` 与 `/dealers`。前端 `.catch(() => ...)` 会静默为空，用户看到的是 0/空租户。
   - 影响：平台后台“报表总览”属于未完成页面。

5. **平台后台部分历史路径仍有 404**
   - API 日志显示历史调用 `/api/admin/platform-menus`、`/api/admin/global-dicts`、`/api/admin/audit-logs`、`/api/admin/api-logs` 等旧路径 404。
   - 影响：如果测试人员访问旧页面或缓存旧 chunk，会出现空页/报错；当前新路径为 `/api/admin/menus`、`/api/admin/dicts/types`、`/api/admin/logs/platform-audits`、`/api/admin/logs/api`。

6. **`/api/stocktakes` GET 返回 500**
   - 代码事实：`StocktakeController` 只有 `POST` 上传，没有 GET 列表。
   - 影响：如果前端或测试人员尝试访问盘点列表，会触发 500；当前业务前台菜单未接入盘点，属于后端能力未闭环。

#### P2 质量与交付问题

7. **后端测试依赖本地 PostgreSQL 5433**
   - 现象：`mvn test` 50 个错误，核心异常为 `Connection to localhost:5433 refused`。
   - 建议：使用 Testcontainers、H2 兼容 profile 或在 README 中明确本地测试数据库启动步骤。

8. **POM 存在 Flyway 依赖重复声明 warning**
   - 现象：Maven warning 提示 `flyway-core` dependency duplicate。
   - 影响：当前不阻断编译，但未来 Maven 版本可能更严格。

9. **前端包体积偏大**
   - 业务端 ECharts/Element/Vant/XLSX chunk 较大；平台后台主 chunk 约 1.19MB。
   - 建议：按路由和图表库做 manualChunks/懒加载，优先拆分后台主包与 XLSX。

10. **部分源码注释存在历史乱码**
    - 示例：多个 Java 类顶部注释、`admin-vue/src/views/tenant/TenantAdmins.vue` 中仍有乱码中文。
    - 影响：不影响运行，但影响维护和交付质量。

    - 后端已有 RMA、分销发货、库存盘点、发票、系统运维等 Controller；业务前台菜单未开放对应页面。
    - 这些多数属于需求文档中“部分上线/规划中”范围，应在交付说明中明确，不应误判为已完成前台功能。
