# v4.6.6 测试环境部署验证报告（2026-09-04）

> 版本：v4.6.6 登录页恢复深色 + 菜单深/浅独立切换（logo 跟随）+ Logo 裁剪增强 + TOP5 经销商全名 + 移动端首页风格升级
> 类型：纯前端 PATCH（frontend-vue + admin-vue + 4 个 logo PNG），**无后端改动、无 Flyway、无 nginx 变更**
> 环境：测试环境 dms-dev.mysolmed.com；正式环境未推送

## 一、需求与实现

- R1 登录页恢复深色：`frontend-vue/src/views/Login.vue` 品牌区由 v4.6.5 品牌蓝渐变恢复为原深灰蓝渐变（#1f2d3d→#34495e）+ 主色右描边，logo 用白色 inverse 版；表单浅色区不变。
- R2 菜单深/浅独立切换：两端 `config/theme-runtime.js` 新增 sider 状态（`dms-theme-preference:sider`，写 `html[data-sider]`），与整页明暗 mode 解耦；`layout/index.vue`、admin `AdminLayout.vue` 顶栏各加「菜单条+日/月」切换按钮，**只切侧边栏**（--dms-sider-*），内容区/主题色不变；偏好持久化。深色=深蓝渐变 #17233d→#111b2f + 白字 + 半透蓝选中底，浅色=白底 + 深灰字 + 浅蓝选中底。admin 激活菜单文字由写死 `#ffffff` 改为 `var(--dms-sider-text-active)`（修复浅底白字不可见）。
- R3 Logo 跟随 + 增强：两端 `components/DmsLogo.vue` 的 `variant=auto` 改为跟随 `data-sider`（深菜单白 logo / 浅菜单深 logo），MutationObserver 同时监听 data-mode、data-sider；4 个 `logo-mark(-white).png` 按 alpha 边界裁剪（512²→266×240，去透明留白），同尺寸下「m」放大约 1.9 倍，浅色底藏青「m」清晰。
- R4 TOP5 全名：根因为工作台 `/home` 渲染的是 `views/Home.vue`（其 TOP5 用 `grid.left:100` 固定、无 axisLabel，长名被裁到只剩后缀），与 `/dashboard` 的 `Dashboard.vue` 是两份独立图表。两处统一修：`grid.containLabel:true` + `axisLabel.formatter` 返回 `\n` 均衡两行断字（≤8 字单行、≤16 字对半两行、超长按 8 字/行），**不设固定 width**（设 width 会触发 echarts 默认 truncate 右对齐截尾），柱条右侧加 ¥ 金额标签，tooltip 全名+金额；TOP 医院图同法。
- R5 移动端首页升级：`views/mobile/MHome.vue` scoped 样式——渐变蓝头部加装饰圆 + logo 半透芯片 + 副标题；本月概览 KPI 纵向卡片 + 蓝/橙彩图标；常用功能宫格 4 色圆角块（蓝/绿/橙/紫循环）；不改动共享 .m-* 全局类。
