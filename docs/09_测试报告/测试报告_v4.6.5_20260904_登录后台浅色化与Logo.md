# v4.6.5 测试环境部署验证报告（2026-09-04）

> 版本：v4.6.5 登录页/平台后台浅色化 + 品牌 Logo 主题自适应 + 寄售库存移出进销存开关
> 类型：纯前端 PATCH（frontend-vue + admin-vue），**无后端改动、无 Flyway 迁移、无 nginx 变更**
> 环境：测试环境 dms-dev.mysolmed.com；正式环境未推送

## 一、需求与实现（v4.6.4 浅色侧栏后的 4 点跟进）

- F1 业务前端登录页未浅色化：`frontend-vue/src/views/Login.vue` 左侧品牌区由深灰渐变改为**品牌蓝渐变**（#1677ff→#46a1ff）+ 装饰圆，logo 放入白色圆角芯片（`variant="dark"` 深色 m 清晰可见），特性圆点改圆形，卡片大圆角 + 蓝色投影；右侧表单保持浅色。
- F2 平台后台（admin-vue）首页/菜单未浅色化：`admin-vue/src/layout/AdminLayout.vue` 侧边栏由深色硬编码改为 token 驱动浅色扁平（白底、圆角 8px、选中浅蓝底 + 主色字、子菜单缩进），logo 区左对齐；`admin-vue/src/styles/tokens.css` 默认 sider token 改浅色并补 active-bg/badge/border；`admin-vue/src/config/theme-runtime.js` 明暗两套分支补齐新 token（深色模式侧边栏仍为深色）；logo 文案精简为「平台后台」避免裁切。后台登录页/首页总览本就是浅色卡片，无需改。
- F3 浅色底上白色 logo 完全不可见：`components/DmsLogo.vue`（frontend-vue 与 admin-vue 各一份）新增 `variant` prop——`auto`（默认，跟随 `html[data-mode]` 明暗，浅色底用深色 m logo、深色底用白 logo，MutationObserver 监听 data-mode 切换）、`light`/`dark` 强制；旧 `inverse` prop 保留兼容。侧边栏/后台用 `variant="auto"`，登录页白芯片用 `variant="dark"`，移动端彩色导航栏保留 `inverse`。
- F4 寄售库存被进销存开关误隐藏：`frontend-vue/src/config/menu.js` 移除寄售库存的 `inventoryOnly: true`（v4.6.4 误加）。寄售库存/资信属**独立业务模块**（modules.js 有独立 consignmentEnabled/授信配置），仅按 `inventory:view` 权限显示，不受进销存 inventoryEnabled 开关影响；库存业务组在进销存关闭时保留「销售出库 + 寄售库存」。

## 二、部署

- 业务前端 `cd frontend-vue; $env:VITE_BASE='/dms/'; npm run build` 通过；admin `cd admin-vue; npm run build`（默认 base `/dms/admin/`）通过。
- `scripts/deploy_front_admin.py` 同时传业务前端 dist 与 admin dist，分别覆盖 /opt/dms/test/frontend/dms 与 /opt/dms/test/frontend/dms/admin；不重启后端、不动 nginx。
