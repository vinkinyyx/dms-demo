## 7. 本次测试发现并修复的缺陷

1. 促销规则全部静默失效（严重）：价格引擎对原生查询返回的 jsonb `rule_detail` 只处理 Map，Hibernate 实际返回 String，导致满减/满赠/满件打折不生效。已增加 String→Jackson 解析分支修复。
2. 满件打折文案错误：value 为优惠比例，「(1−rate)×10」才是中文折数（0.10 优惠=9 折，原误显「10 折」），已修正。
3. 销退列表看不到新 RMA 单、详情 404 噪音：新增 `/api/rma/orders/unified` 合并两表，前端按 r/l 前缀路由，已修复。
4. 客户注册写 SYSTEM 租户、审核建地址 status NOT NULL 违约：已修复租户解析与地址字段补全。
