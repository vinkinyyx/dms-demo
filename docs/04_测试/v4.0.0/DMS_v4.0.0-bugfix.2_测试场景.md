# DMS v4.0.0-bugfix.2 测试场景

## 1. 产品管理
1. 列表状态下拉有“生效/失效”选项，分类下拉加载分类树，选择后筛选生效。
2. 产品编码链接和查看按钮进入只读页，非编辑态。
3. 产品编辑页和只读页无单价、税率字段；列表无参考单价、税率列。
4. 列表无批量删除按钮。
5. 只读页底部展示操作日志（创建、编辑、字段变更）。
6. 新增/编辑保存后只读页字段完整、布局整齐，备注/长文本不被截断。

## 2. 产品组合（BOM）
1. BOM 编码链接和查看进入只读页，展示母件、版本、子件、操作日志。
2. 列表无删除按钮；接口 DELETE 返回不支持。
3. 当前版本 BOM 有“新建版本”按钮；点击后原版本变历史，新版本号系统自增，母件头只读。
4. 新版本只允许修改子件（增删改子件与配比），保存后为当前版本。
5. 编辑状态下无法直接把当前版本改为历史；版本号字段不可手填。
6. 编辑页/只读页布局整齐，子件表宽度合适。

## 3. 产品价格
1. 价格创建后不可编辑业务字段、不可删除；只能生效/失效；DELETE 返回业务错误。
2. 列表有查看按钮进入只读页。
3. BOM 母件产品不出现在价格产品选择器中；子件/普通 SKU 可维护。
4. 价格按经销商维护；全局价和经销商价均可建；同 SKU+合作方重叠时间段保存失败。
5. 含税销售价和税率可编辑，不含税销售价只读并自动计算保留 4 位小数（如 113/1.13=100.0000）。
6. 含税采购价、税率同理联动不含税采购价。
7. 币种显示为 CNY/USD 等代码；报表和价格详情带出币种。

## 4. 促销规则
1. 规则编码链接与查看进入只读页，含操作日志。
2. 无删除按钮；只有启用/停用，到期自动失效。
3. 选“满A赠B”时，必填命中对象A、门槛数量A、赠品B(不可BOM母件)、赠品数量、赠送方式。
4. 选“满A减钱”时，必填命中对象A、门槛数量A、减免金额；无赠品字段。
5. 表单无“折扣方式/折扣值”字段。
6. 满A按数量门槛触发（非金额）。

## 5. 销售订单
1. 订单号链接与查看进入只读页，含操作日志；编辑页有提交按钮。
2. 编辑/只读页布局紧凑整齐，备注为多行文本，字段不截断。
3. 列表状态、经销商下拉有选项；日期范围筛选生效；筛选与按钮对齐。
4. 明细选择 BOM 母件后自动展开子件，以树形展示；母件行可改数量，子件数量按配比联动且只读。
5. 母件行不显示折扣输入；折扣只能加在子件/普通 SKU 行。
6. 行折扣金额按整行计算：SKU 10个、行金额折扣 100 元，整行减 100 而非 1000。
7. 命中促销时明细展示促销标签和促销折扣金额。
8. 保存/提交不做商品授权校验，无“订单授权校验失败”提示。
9. 连续点击保存不弹“请求正在处理中”，按钮 loading，不产生重复单据。
10. 点击取消返回列表，无 404。
11. 已审批订单详情对租户管理员显示“模拟创建出库”按钮，其他角色不可见；点击生成出库结果不扣库存。
12. 整单固定金额折扣按行金额占比分摊到每个 EA（落 unit_price），出库行继承该单价；销退按该单价退货。
13. 存在带价格的出库测试数据（整数数量），可供销退选择。

## 6. 销退订单
1. 编辑/只读页布局整齐，备注多行，字段完整。
2. 选择出库单弹窗中不显示无可退数量的单据。
3. 发货数量、退货数量均为整数；历史小数数据（GI-20260816-00009 等）已修正。
4. 退货自动带出原订单/出库行最终含税单价。
5. 提交审批成功后跳转列表或详情，无 404。
