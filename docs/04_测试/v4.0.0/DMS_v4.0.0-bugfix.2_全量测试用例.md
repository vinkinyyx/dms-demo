### 8.2 本轮额外修复（回归中发现）

| 模块 | 问题 | 修复 |
|---|---|---|
| 通用列表 | `computed(() => effectiveRowButtons)` 错误地返回函数本身，行操作按钮不随异步布局加载刷新，操作列整列空白 | 改为 `computed(() => effectiveRowButtons())`，调用方改用 `.value` |
| 通用列表 | 自定义行按钮（BOM 新建版本、价格生效/失效、促销启停用）被 `rowActionVisible` 中 `legacy===null` 判空逻辑误隐藏 | 对 `newVersion/activate/deactivate` 直接放行 |
| 通用列表 | BOM 等含 `versionStatus` 的 `when` 过滤误伤无版本字段的模块（价格/促销的启停用按钮被隐藏） | `versionStatusIn` 仅在 `row.versionStatus != null` 时生效 |
| 操作日志 | 详情页调用 `/api/operation-logs?businessType/businessId` 参数名错误，日志始终加载失败 | 统一为 `/api/operation-logs?resourceType/resourceId`，并合并 `/api/operation-log/list/{bizType}/{id}`（`@OperationLog` 表），字段统一为 username/action/changes/atTime |
| 操作日志 | 销退只读页缺操作日志区 | `SalesReturnEdit.vue` 只读态新增操作日志时间轴并加载合并日志 |
| 订单列表 | 状态/经销商筛选下拉为空（`sales_order_status`/`dealer` 字典未播种） | `filterOptions` 回退到列内联 options，并对 dealer 走 `/api/lookups/dealers` 远程加载 |
| 订单列表 | 顶部日期筛选 `dateFrom/dateTo`、`dealer` 后端未识别，筛选无效 | `SalesOrderController` 新增 `dateFrom/dateTo/dealer` 参数别名，统一映射到 created_at / dealer_id |
| 订单 | “返回/取消/保存后跳转”使用 `/orders`（PC 端不存在），导致 404 | `OrderDetail.vue`、`OrderCreate.vue` 统一跳转 `/m/orders` |
| 币种 | 币种下拉显示中文“人民币/美元” | `CURRENCIES` label 改为字母代码 `CNY/USD/EUR` |

### 8.3 关键业务数值校验（API 链路）

BOM 母件数量 2，子件按配比展开（A qty=2、B qty=6），整单金额折扣 100：
- 子件最终金额 160.00 / 240.00，PARENT 汇总 400.00
- 整单金额折扣 100 按各行金额比例分摊：A 分摊 40.00、B 分摊 60.00（合计 100.00）✓
- 行金额折扣用例（子件 A 配比1@100、B 配比2@50、母件数量2）：行折扣 100 仅作用一次（不按 EA/子件数量倍增），最终金额 300.00 ✓
- 模拟出库成功，销退候选/明细带出原分摊后单价（4 位小数），销退创建+提交成功 ✓
