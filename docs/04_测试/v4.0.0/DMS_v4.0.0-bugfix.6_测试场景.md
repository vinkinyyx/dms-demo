# DMS v4.0.0-bugfix.6 测试场景

## 1. 通用列表
1. 打开各业务列表，编号/编码可点击，名称等非编号字段不可点击。
2. 编号链接和“查看”均进入只读页；“编辑”进入编辑页。
3. 操作按钮超过 2 个折叠展示；draft/rejected 等状态的编辑按钮可见。
4. 关键词输入一个或多个编码/名称片段（空格/逗号/中文逗号分隔），列表返回任一关键字段命中的记录。
5. 点击新建，抽屉高度覆盖列表+筛选区域，且表单初始为空。

## 2. 产品组合 BOM
1. active BOM 行显示查看、新建版本，不显示删除。
2. 点击新建版本，生成 draft 并直接打开编辑抽屉；原 active 保持 active。
3. draft 行显示查看、编辑、发布；编辑只允许改子件和有效期等非母件头部字段。
4. BOM 子件列展示子件 SKU 编码和名称，不显示数字 ID。
5. 子件数量填 0 或小于 1 时无法保存并提示。
6. 点击母件 SKU 编码排序，列表正常排序，不报 500。

## 3. 产品价格
1. 新建采购价：可选择单品；选择 BOM 母件时被后端拒绝。
2. 新建销售价：未选经销商不能保存；选择 BOM 母件后自动展开 active 子件。
3. 每个子件可维护含税销售价和税率，不含税价自动保留 4 位小数。
4. 保存 BOM 销售价后，列表只出现子件价格，不出现母件 0 元价格。
5. 同一经销商、同一子件重复创建有效价格应被拒绝。
6. 价格详情可正常打开；删除按钮不可用；金额字段不可编辑，只能生效/失效。
7. 币种显示为 CNY/USD 等字母编码。

## 4. 销售订单
1. 新增订单表单初始为空，不携带上一张订单数据。
2. 选择经销商后添加 BOM 母件，自动展开子件；子件数量由母件数量和配比计算且不可编辑。
3. 母件单价/金额为 0，不显示行折扣；子件显示价格、折扣和金额。
4. 单行 10 个、行折扣金额 100 时，整行折扣总额为 100，不是 1000。
5. 整单百分比折扣按折后比例计算，例如折前 4000、10% 后最终约 3600。
6. 编辑页和只读页展示订单总价，且金额与明细合计一致。
7. 保存草稿后列表显示编辑；提交后不显示编辑和删除。
8. 已审批未出库订单显示“生成销售出库”和“取消”；已有出库数量时不显示取消。
9. 连续保存/提交不出现重复提交误报。
10. 保存/提交不触发授权校验。

## 5. 销退与出库
1. 销退新建、查看、编辑均可打开，不白屏。
2. 销退提交后状态进入待审批或自动审批，不停留草稿。
3. 审批完成的销退单显示/可触发生成红字销售出库。
4. 选择原发货单时只列出仍有可退数量的单据。
5. 退货数量为整数；可退数量随已退数量更新。
6. 销售出库列表链接和查看可打开；确认按钮不得跳转 404。

## 6. 操作日志
1. BOM、价格、促销、销售订单、销退订单只读页均显示操作日志。
2. 创建、提交、审批、取消、价格生效/失效、BOM 发布等动作产生日志记录。
