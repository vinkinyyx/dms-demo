# 前后台功能迁移清单

**版本**：v1.0  
**日期**：2026-08-02

---

## 1. 迁移目标

将当前混合在业务前台中的平台级后台能力抽离到独立平台后台，业务前台只保留租户内业务和租户管理员能力。

当前入口：`frontend-vue/src/views/Admin.vue`，其中包含系统概览、审计日志、登录日志、通知、系统参数、数据字典、租户列表、RBAC 矩阵、运维、操作日志下载等能力，需要拆分迁移或废弃。

---

## 2. 迁移到平台后台的功能

| 功能 | 当前位置 | 目标处理 |
|---|---|---|
| 租户列表 | `Admin.vue` / `/api/tenants` | 迁入平台后台，拆分为厂家租户和经销商租户管理 |
| 创建租户 | `Admin.vue` | 迁入平台后台，支持开通厂家/经销商、绑定 dealer、创建租户管理员 |
| 数据字典 | `Admin.vue` / Dict API | 迁入平台后台，作为全局字典 |
| 审计日志 | `Admin.vue` | 迁入平台后台日志中心 |
| 登录日志 | `Admin.vue` | 迁入平台后台日志中心 |
| 操作日志下载 | `Admin.vue` / `/api/admin/op-logs/download` | 迁入平台后台日志中心，改造为列表 + 文件下载 |
| RBAC 矩阵 | `Admin.vue` | 迁入平台后台默认角色和权限模板管理 |
| 系统参数 | `Admin.vue` | 迁入平台后台全局配置或废弃不用项 |
| 缓存状态/刷新 | `Admin.vue` | 迁入平台后台运维能力 |
| 超时检查 | `Admin.vue` | 迁入平台后台运维任务或废弃 |
| 系统概览 | `Admin.vue` | 改造为平台后台仪表盘 |
| 通知消息 | `Admin.vue` | 暂不迁入第一期或改为平台公告设计 |

---

## 3. 业务前台保留的功能

| 功能 | 说明 |
|---|---|
| 租户内用户管理 | 租户管理员创建、停用、解锁普通用户 |
| 租户内角色管理 | 租户管理员在授权范围内自建角色 |
| 用户角色分配 | 给本租户用户分配角色 |
| 普通用户重置密码 | 租户管理员操作 |
| 个人资料与修改密码 | 当前用户自助 |
| 业务菜单和页面 | 根据权限和平台 UI 配置渲染 |
| 产品对码 | 仅厂家租户可见 |
| 归属经销商只读列表 | 仅厂家租户产品对码等场景使用 |

业务前台不再提供全局租户管理、全局字典、全局菜单、全局日志和平台运维入口。

---

## 4. 前端调整

### 4.1 `frontend-vue`

- 移除菜单中的“后台管理”入口。
- 删除或停用 `src/views/Admin.vue` 平台后台页面。
- 移除普通用户访问 `/admin` 的路由。
- 登录后根据租户类型、角色和权限加载菜单。
- 增加厂家产品对码页面和归属经销商只读选择接口。
- 全局字典改为只读。
- 页面字段、筛选项改为读取平台 UI 配置。

### 4.2 新建 `admin-vue`

建议技术栈保持与现有前端一致：Vue 3 + Vite + Element Plus。

模块：

- 登录页。
- 仪表盘。
- 厂家租户管理。
- 经销商租户管理。
- 租户管理员管理。
- 默认角色与权限模板。
- 菜单配置。
- 页面字段配置。
- 筛选配置。
- 全局字典。
- 日志中心。
- 运维工具。

独立部署：

- 开发环境独立端口。
- 生产环境独立路径或独立域名。
- API 基址指向后端 `/api/admin`。

## 5. 后端调整

### 5.1 新增/调整模块

- `adminauth`：平台后台登录、token、当前用户。
- `admintenant`：厂家和经销商租户开通、停用、启用。
- `adminbinding`：经销商租户与 dealer 绑定。
- `adminusermgmt`：租户管理员管理。
- `adminconfig`：菜单、页面字段、筛选配置。
- `admindict`：全局字典管理。
- `adminlog`：日志中心查询和报文下载。
- `productmapping`：厂家前台产品对码。

### 5.2 租户隔离改造

- 扩展 `TenantContext`。
- 平台后台请求不设置业务租户上下文。
- 业务请求从 token 解析租户，不信任前端传参。
- 扫描所有业务表和查询，补齐 `tenant_id` 条件。
- 对厂家和经销商关系数据增加所属厂家校验。
- 增加跨租户访问安全日志。

### 5.3 日志改造

- 接口日志元数据入库。
- 原始请求/响应报文写 MinIO。
- 增加脱敏工具。
- 增加日志清理任务。
- 平台后台日志列表支持多条件筛选和文件下载。

## 7. 实施顺序建议

1. 数据库增量迁移：扩展租户表，新增绑定、对码、平台配置和日志表。
2. 后端平台认证和租户开通。
3. 后端租户隔离和权限校验加固。
4. 新建 `admin-vue` 平台后台。
5. 迁移租户、字典、菜单、页面配置、日志功能。
6. 前台移除旧后台入口并接入新配置。
7. 厂家前台实现产品对码。
8. 准备 seed 数据并联调。
9. 回归租户隔离、权限、日志和导入功能。

---

## 8. 第一期废弃或暂不做

- 不做模拟登录。
- 不做租户级私有字典。
- 不做租户级页面自定义。
- 不做平台后台多角色。
- 不做独立部署控制台。
- 不做基础设施监控大盘。
- 不做计费和套餐。
