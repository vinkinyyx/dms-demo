# 平台后台设计文档索引

本目录用于存放平台后台、多厂家多租户隔离和前台迁移相关设计文档。

## 文档列表

| 文档 | 说明 |
|---|---|
| `01_平台后台需求范围总结.md` | 总体需求范围、角色边界和一期范围 |
| `02_架构与多租户隔离设计.md` | 三层架构、部署、租户上下文、数据隔离、缓存和文件隔离 |
| `03_角色权限与RBAC设计.md` | 前后台角色、权限点、数据权限、销售岗位权限 |
| `04_租户开通与经销商绑定设计.md` | 厂家/经销商租户开通、dealer 绑定、租户状态和管理员管理 |
| `05_菜单与页面字段筛选配置设计.md` | 平台统一菜单、字段、筛选项配置和缓存下发 |
| `06_全局字典管理设计.md` | 全局字典范围、结构、后台维护和缓存 |
| `07_产品主数据对码设计.md` | 厂家产品与经销商产品一对一映射和 Excel 导入 |
| `08_日志审计与监控中心设计.md` | 操作、登录、接口、异常、慢接口日志和报文文件 |
| `09_数据库设计.md` | 新增表、扩展字段、索引和迁移建议 |
| `10_API设计.md` | 平台后台、前台配置、产品对码和日志接口 |
| `11_前后台功能迁移清单.md` | 旧后台迁移、前台保留功能、实施顺序 |
| `12_测试数据方案.md` | 多厂家、经销商、角色、岗位、对码和日志测试数据 |

## 阅读顺序

1. 先读 `01` 了解需求范围。
2. 再读 `02`、`03`、`04` 明确核心架构和权限。
3. 然后读 `09`、`10` 作为开发依据。
4. 最后参考 `11`、`12` 做迁移、联调和测试。
