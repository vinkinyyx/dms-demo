# 产品主数据对码设计

**版本**：v1.0  
**日期**：2026-08-02

---

## 1. 目标

厂家和经销商各自维护自己的产品主数据。产品对码用于建立某厂家产品与该厂家下属经销商产品之间的一对一关系。第一期只维护对码关系，主要服务报表汇总，不做跨租户业务单据查询，不做厂家实时查看经销商订单和库存。

---

## 2. 维护入口

产品对码放在厂家租户前台，不放在平台后台。

- 厂家管理员、客服或有权限的厂家角色可维护。
- 厂家只能选择归属自己的经销商租户。
- 厂家只能选择自己的产品和经销商产品。
- 经销商租户不维护对码。
- 平台后台不维护具体业务对码。

厂家前台需要提供“归属本厂家的经销商租户只读列表”，用于对码导入和查询。

---

## 3. 对码规则

- 厂家产品与经销商产品必须一对一。
- 一个厂家产品不能对码同一经销商的多个产品。
- 一个经销商产品不能对码同一厂家的多个产品。
- 一个对码关系必须明确厂家租户和经销商租户。
- 对码关系支持启用、停用。
- 停用的对码不参与报表汇总。
- 同一经销商租户下，经销商产品编码必须可唯一匹配一个产品。
- 对码不改变双方产品主数据归属。

---

## 4. 页面功能

厂家前台产品对码页面建议包含：

- 按经销商租户筛选。
- 按厂家产品编码/名称筛选。
- 按经销商产品编码/名称筛选。
- 按状态筛选。
- 对码列表。
- 手工新增/编辑/停用。
- Excel 批量导入。
- 导入模板下载。
- 错误报告下载。
- 导出对码结果。

---

## 5. Excel 导入

### 5.1 模板字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 经销商租户编码 | 是 | 必须归属当前厂家 |
| 经销商产品编码 | 是 | 经销商租户内产品编码 |
| 厂家产品编码 | 是 | 当前厂家租户内产品编码 |
| 包装单位 | 否 | 预留报表换算 |
| 换算率 | 否 | 预留报表换算 |
| 备注 | 否 | 说明 |

### 5.2 导入流程

1. 下载模板。
2. 上传 Excel。
3. 后端解析并生成导入批次。
4. 预览成功数据和错误数据。
5. 用户确认后正式写入。
6. 返回成功数量、失败数量、错误报告。

### 5.3 校验规则

- 经销商租户存在、启用且归属当前厂家。
- 厂家产品存在且属于当前厂家。
- 经销商产品存在且属于该经销商租户。
- 同一厂家产品未与该经销商其他产品对码。
- 同一经销商产品未与该厂家其他产品对码。
- Excel 内行不能重复。
- 包装单位和换算率格式正确。
- 停用状态只能使用允许值。

导入时需要事务控制。单条失败是否整批失败：第一期建议“预览阶段全部校验，确认导入时有效数据入库、错误数据出报告”，但为了数据清晰，也可以整批失败。建议采用前者。

---

## 6. 报表用途

对码关系用于后续报表按厂家产品口径汇总经销商数据。第一期只维护关系，不实现跨租户数据同步。

后续报表汇总时需要注意：

- 只统计启用状态对码。
- 只处理归属当前厂家的经销商租户。
- 按包装单位和换算率做数量换算。
- 未对码产品进入异常清单。

---

## 7. 审计

以下操作记录业务操作日志：

- 新增对码。
- 编辑对码。
- 启用/停用对码。
- 批量导入。
- 导出对码。

日志需要记录厂家租户、经销商租户、厂家产品、经销商产品、操作人和操作时间。
