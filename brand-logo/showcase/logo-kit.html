5不同底色适配验证

同一图形标在常见底色上的表现：浅底用藏青版，深底 / 照片底用反白版，青底用藏青版。

白底 → 藏青版 ✓ 清晰
浅灰底 → 藏青版 ✓ 清晰
藏青底 → 反白版 ✓ 清晰
近黑底 → 反白版 ✓ 清晰
照片/渐变深底 → 反白版 ✓ 清晰
青底 → 藏青版 ✓ 清晰
底色选择规则：背景明度高（白 / 浅灰 / 浅彩）用 mark / wordmark（藏青）；背景明度低（藏青 / 黑 / 深照片）用 *-white（反白）。青点在所有版本中保持 #00B4D8 不变，是品牌记忆点。禁止在藏青底上再放藏青 logo、或在白底上放反白 logo（会看不见）。
