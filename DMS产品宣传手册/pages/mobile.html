HOSPITALS & PRODUCTS

终端医院与产品物料、BOM 组合品

统一维护医院 / 科室 / 终端客户档案与经销商覆盖关系；产品、规格、分类、条码多维度管理，并将固定 BOM 版本与子件配比纳入同一工作台，母件下单自动展开子件、单品价与子件价双轨计价。

医院 / 终端管理

医院 / 终端管理

维护医院等级、科室、终端类型与重点客户，关联经销商覆盖关系，为手术报台与流向分析提供基础。

产品物料与 BOM 组合品
  • 产品主数据：SKU、规格、分类、条码、注册证多维度管理，支持多规格医疗器械体系。
  • 固定 BOM 版本：生效期与版本状态独立管控，历史版本可追溯。
  • 配比自动展开：母件下单后子件按 BOM 配比自动展开为可编辑行，出库以子件 SKU 扣减库存。
  • 价格双轨：单品价与 BOM 子件价双轨维护，同一 SKU 可同时维护两套价格。
CONTRACTS & AUTHORIZATION

合同 · 模板 · 授权一体化

合同模板条款库、合同签署归档与授权备案在同一工作台管理；合同与授权联动生效、到期提前预警，授权产品 / 区域 / 期限自动校验，杜绝超授权经营。

合同 · 模板 · 授权
  • 合同模板库：预置标准模板与条款，一键生成合同、统一审批归档。
  • 授权备案：按经销商、产品、区域、医院维度签发授权，范围与期限系统校验。
  • 联动生效：合同与授权联动生效，超授权范围下单自动拦截。
  • 到期预警：合同、资质、授权到期前自动提醒责任人。
SALES ORDERS

销售订单与智能计价

支持 BOM 展开、分级价格、整单与行折扣、代金券分摊，价格引擎实时校验，下单即得准确金额；从下单、审批到发货、签收、退货的完整链路可视。

销售订单
  • 智能取价：合同价 / 客户专属价 / 全局分级价按优先级自动匹配，价格来源可追溯。
  • BOM 自动展开：母件下单自动按配比展开子件为可编辑行，单品价与子件价双轨计价。
  • 促销与折扣：整单、行折扣、满减满赠与代金券按比例分摊，命中结果实时提示。
  • 无价格拦截：缺少有效价格时明确拦截并提示产品编码 + 名称，杜绝错单。
销售退货 / 逆向流程

销售退货与逆向流程

销退必须先选经销商再选出库单，可退数量按来源发货行锁定；退货审批通过后库存自动回写、金额红冲，代金券状态同步返还。

INVENTORY

库存批号追溯与寄售管理

批号、序列号、效期维度的实时库存，合格 / 待验 / 不合格状态分明，出入库全程可追溯；品牌方货物前置到经销商仓库的寄售业务按实际消耗结算，在库 / 锁定 / 已消耗数量清晰。

库存与批号追溯
  • 多维库存：批号 / 序列号 / 效期维度实时库存，合格、待验、不合格状态隔离。
  • 正反向追溯：按批号 / 序列号 / UDI 全链路追溯出入库流向。
  • 近效期预警：批次效期自动标红预警，效期锁定防过期出库。
销售出库 / 追溯

销售出库与流向追溯

按订单拣货发货，支持批次 / 序列号指定与部分发货；出库即时扣减库存、回写订单状态，随货同行单一键打印。

寄售库存管理

寄售库存管理

品牌方货物前置到经销商仓库，按实际消耗结算；寄售仓库存独立台账，在库 / 锁定 / 已消耗数量实时可见，消耗后自动回写结算与补货建议。

SURGERY REPORT

手术报台 · 临床数据真实回流

跟台人员现场录入手术与植入产品，支持拍照取证，UDI / 批号关联高值耗材，临床使用数据真实回流，形成从出库到医院使用的闭环追溯。

手术报台列表
  • 现场录入：手术信息与植入产品现场录入，报台单号 / 经销商 / 医院 / 术式一目了然。
  • 拍照取证：术中资料、包装标签拍照上传，影像与业务单据自动关联。
  • UDI / 批号：扫描或录入 UDI、批号、序列号，精确到单件使用去向。
  • 统计分析：按医院、术者、产品维度统计手术量与耗材使用量。

PROMOTION

促销引擎与 V4 计价

V4 计价引擎贯穿订单全流程：满 N 件打折、满减、满赠三类促销 + 产品/客户全局折扣 + 代金券 + 一口价 + 整单 0 金额，互斥矩阵清晰，同 SKU 同时段唯一防冲突，分摊口径精确到分。

促销规则
  • 三类促销：满 N 打折、满 N 减金额、满 N 赠品（支持每满 N 循环），同 SKU 同时段唯一防冲突。
  • 代金券：厂家统一发放、一单一张、范围与门槛校验，抵扣不摊入行单价防退货套现。
  • 互斥模式：一口价 / 整单 0 / 代金券两两互斥，差额按行金额比例分摊到 EA 单价。
  • 全局折扣：产品 / 客户全局折扣按时间段独立维护，同产品 / 客户时间段不重叠。
OPEN API

开放接口与 ERP 集成

提供 HMAC-SHA256 签名的对外开放 API，销售订单与销退审批后自动推送 ERP，支持回调出库结果与幂等防重，入站出站调用全量日志可查可追溯。

接口调用日志
  • HMAC 签名鉴权：AppKey / AppSecret 维度管控，签名防篡改。
  • ERP 双向集成：订单 / 销退审批后推送 ERP，回调出库结果，biz_key 幂等防重。
  • 全量日志：入站出站方向、方法、路径、状态码、耗时、payload 与链路追踪完整留痕。
