01 监管追溯 · 系统骨架

进销存全闭环，批号 / 序列号 / UDI 全程可追溯

从采购下单到终端发货，每一箱、每一件耗材都有据可查，满足医疗器械强监管追溯要求。

医疗器械经销的核心是「账实相符、流向可追」。DMS 打通采购、收货、库存、销售、出库、退换货全链路：采购订单审批后自动生成收货单，支持多次分批收货并进入待检状态；库存按合格、待检、不合格三态管理，配合跨仓移动、状态调整、盘点与效期预警；销售订单审批通过自动生成出库单，发货时按批号、序列号逐件扣减，序列号产品一件一码全程留痕。销退、采退自动生成对应出入库单，每一笔库存变动都写入不可篡改的流水台账。

采购订单 / 采退订单 收货入库 / 销售出库（多次部分收发） 三态库存 + 隔离态 批号 / 序列号 / 效期一物一码 库存移动 / 调整 / 盘点 效期预警与呆滞分析 序列号追溯 BOM 组合品 / 产品分类

02 行业特色 · v4.5.0

厂家与经销商跨租户协同，一套平台串起供应链

厂家和下游经销商在同一平台上做生意，采购、销售、出库、收货单据自动流转，物料编码自动转换。

传统模式下，厂家与经销商各用一套系统，订单靠电话、对账靠 Excel。DMS 以多租户 SaaS 模式把双方放在同一平台：经销商向「平台厂家」下采购单，系统自动在厂家租户生成销售订单并完成物料编码转换；厂家发货出库后，经销商租户自动收到待确认的入库单。整个过程通过产品对码自动转码、行级台账溯源、幂等防重，缺对码会明确阻断并提示是哪个产品。

产品对码（厂家↔经销商一对一映射） 采购单 ↔ 销售单自动生成 出库单 ↔ 收货单自动流转 跨租户单据台账行级溯源 幂等防重 + 缺对码阻断 租户开通与一对一绑定

03 交易正确性

智能计价引擎，合同价、折扣、促销、代金券一键算清

复杂商务政策交给系统，下单即实时试算，价格优先级清晰、金额分毫不差。

医疗器械价格体系复杂：合同协议价、客户专属折扣、产品全局折扣、满减促销、代金券层层叠加。DMS 的 V4 计价引擎按「合同价格 → 产品/客户全局折扣 → 促销规则 → 标准价」的固定优先级自动计算，下单时实时预览试算结果。支持满减、数量折扣、赠品、一口价、零金额订单、代金券等多种模式；代金券从模板、发放到核销全链路管理，订单提交即占用、审批通过核销、审批驳回自动返还。BOM 组合产品由子件承载价值、组件价智能回退。

04 行业特色 · v4.4.0

寄售代销闭环，先铺货后开票，额度风险可控

支持「先发货铺货、按实际使用开票」的高值耗材代销模式，寄售台账细到批号序列号。

高值耗材普遍采用寄售模式：厂家先把货铺到经销商处，实际消耗后才开票结算。DMS 完整覆盖这一业务：补货订单以 0 金额铺货发货，自动计入经销商寄售台账（按经销商 + 产品 + 批号 + 序列号维度）；开票订单必须从寄售库存中整行拣选，提交即预占、审批通过实扣、驳回自动释放；错补、撤回可开红字补货单红冲。系统同时管理经销商信用额度、账期与寄售额度，超额或超账期自动触发审批而非简单拦截。

补货订单（0 金额铺货，禁折扣/促销/券） 开票订单从寄售库存整行拣选 提交预占 / 审批实扣 / 驳回释放 红字补货单红冲（SOR） 信用额度 / 账期 / 寄售额度 超额超期触发审批（非硬拦截）

05 业务正确性闸门

统一审批工作流，关键动作有把控、关联资源自动回滚

销售、采购、合同、退换货全部走统一审批，审批通过自动建单，驳回自动回滚库存与代金券。

DMS 把所有关键单据纳入统一工作流：销售订单、采购订单、销退、采退、合同都可配置审批节点与审批人。审批通过后系统自动触发下游动作（如销售订单自动生成出库单）；审批卡片以结构化方式展示金额、对方、产品明细等关键信息，审批人一目了然。更重要的是，审批驳回、退回、撤回时，系统会自动回滚已占用的代金券、锁定的库存、预占的寄售额度和可退数量，绝不出现「单据退回了、资源却没释放」的账务错乱。

审批流配置 / 节点 / 策略 条件分支 / 会签 / 或签 通过自动建单（GI 出库等） 驳回回滚：券 / 库存 / 寄售预占 / 可退量 超时催办升级 + 委托代理 PC + 移动端审批闭环

06 行业特色 · 合规证据

手术报台，移动端扫码拍照记录产品真实流向

销售在手术室现场扫码填报，产品用到哪位患者、哪个批号全程留痕，合规追溯到终端。

植入类耗材要求记录产品在手术中的真实使用情况。DMS 手术报台让销售人员在手术现场用手机完成填报：扫描产品条码或 UDI 自动带出产品、批号、序列号，现场拍照上传凭证，填写医院、医生、患者与使用数量。系统按销售授权范围过滤经销商与医院，销售只能看到自己负责的客户数据。报台数据与出库、库存追溯关联，成为产品流向终端医院的最终凭证；管理层可通过手术报台统计报表，按医院、产品穿透到每一台手术明细。

扫码自动带出产品 / 批号 / 序列号 现场拍照上传凭证 医院 / 医生 / 患者 / 仓库登记 按销售授权范围过滤 手术报台统计报表（穿透明细） 与出库 / 库存追溯链路关联

07 移动抓手 · 高频场景

移动销售工作台，手机上完成下单、报台、看业绩

销售人员真正高频的三件事——下单、报台、看业绩，一部手机全部搞定。

销售常年在医院和客户现场，PC 不在手边。DMS 移动端围绕销售真实场景精简设计：首页展示个人今日/本月订单与报台 KPI；订单模块支持手机下单，选客户、选仓库、选产品，行内直接编辑数量、单价、税率，底部实时合计；报台模块扫码即录；「我的」查看个人业绩与待办。v4.4.4 更推出「智能下单」对话式向导，销售跟着提示一步步就能完成复杂订单。

09 商务管控

合同模板驱动 + 授权前置，商务政策落到系统硬约束

合同从模板成稿到审批生效全线上管理，授权范围决定能订什么货，超范围根本下不了单。

商务政策不能只停留在纸面上。DMS 合同工作台管理合同全生命周期：基于 Word 模板自动回填字段生成合同成稿，版本快照与审批轮次全程留痕，生效后合同价格明细自动成为计价的最高优先级。授权管理记录每个经销商可经营的产品范围与有效期，支持临时授权；下单和出库时系统前置过滤，超出授权范围或已过期的产品根本无法选择，从源头防止超范围、超期经营。
