## 今日设计要点（2026-08-31）

### v4.5.3（PATCH，纯前端 UI 增强，无 Flyway）

- **面包屑导航**：内容区顶栏 Breadcrumb.vue（el-breadcrumb，separator="/"），路径「首页 / 菜单分组 / 菜单 / 详情」；中间层级可点击回跳，末级为当前页纯文本。
- **多菜单页签 Tags-View**：TagsBar.vue 横向 chip 栏（el-scrollbar，激活页签自动居中）；chip 点击切换、×关闭、鼠标中键关闭、右键菜单（刷新页面/关闭页签/关闭其他/关闭全部）；首页 affix 固定。
- **元信息解析**：utils/pageMeta.js 由 config/menu.js 扁平化 FLAT_MENU，resolvePageMeta 匹配链 = /home 特判 → fullPath/path 精确 → 前缀 → 27 条 DETAIL_PARENT 详情页正则 → 兜底「业务模块」；tagKeyOf 菜单页用 fullPath（报表 query 区分）、非菜单页用 'name:'+name。
- **状态与持久化**：Pinia store/tags.js（tags/activeKey/reloading），sessionStorage key `dms:tags-view`（值为 tag 数组本身），F5 恢复；退出登录 reset。
- **缓存与刷新**：layout/index.vue router-view 外 `<keep-alive :max="12">`（meta.noCache 除外）；「刷新页面」= reloading v-if 销毁 router-view 组件 → 60ms refreshDone 重建。
- **样式**：全用 DMS CSS 变量，深色模式 `html[data-mode='dark']` 覆盖；构建必须 VITE_BASE=/dms/，测试服静态部署 = 解压 dist 到 frontend/dms/（保留 admin）+ nginx -t + reload。

### v4.3.0（MINOR，R1–R9，Flyway V121–V133）

- V4 计价引擎：定价优先级链 **合同价格 → 全局折扣（产品/客户）→ 促销（QTY_DISCOUNT/QTY_REDUCE/GIFT）→ 标准价**；模式 NORMAL/FIXED_PRICE/ZERO_ORDER/VOUCHER；`POST /api/v4/calc/preview`。
- 代金券：券模板/发放/核销；ISSUED → USED（下单占用）→ 审批通过核销 / 拒绝释放。
- 客户自助注册：H5 注册 → 平台审核 → 自动建 dealer + CUSTOMER 账号。
- 销退单：支持关联同一经销商多张出库单（rma_order_outbound_refs）。
- 专版设计：`docs/02_设计/v4.3.0/总体设计.md`、`docs/02_设计/v4.3.0/订单折扣与促销规则说明书.md`。
